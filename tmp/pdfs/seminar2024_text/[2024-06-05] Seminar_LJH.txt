VISUAL-LIDAR FUSION ALGORITHM
• Lidar-Monocular Visual Odometry using Point and Line Features (LIMO)[16]
• Target: LiDAR-monocular visual odometry pose estimation accuracy 
improvement
• Lidar-monocular visual odometry method combining both point and line features in a 
purely geometric
• Monocular camera-based point and line detection
• Extract the depth of detected points and lines by matching 3D point-cloud to RGB image
• Using the above information, estimate the vehicle’s pose.
