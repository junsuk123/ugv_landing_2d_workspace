## 1. 변경 범위와 전체 경로

현재 공통 관측을 물리·운동 특징과 접근·접촉 특징으로 배치하고, 두 단계의 관계 집계로 `LandingContext` 임베딩을 생성한다.

현재 공통 관측 \(o_t\in\mathbb R^{10}\)을 특징 행렬 \(X_t\in\mathbb R^{6\times7}\)로 변환한다. 공유 사영으로 각 노드를 8차원으로 만든 뒤, 같은 R-GAT 파라미터로 메시지 전달을 두 번 수행한다. `LandingContext` 노드에서 선택한 \(g_t\in\mathbb R^8\)과 원 관측을 결합한 18차원 입력을 기존 MLP Actor에 전달하여 가우시안 행동 평균 \(\mu_t\in\mathbb R^2\)를 생성한다.

위 경로는 한 결정 시각 안에서 계산된다. 별도 관측 이력, 프레임 스택, 과거 행동, 시간 간선, 순환 네트워크, 누적 단계 플래그를 사용하지 않는다. 기존 항법·UGV 추정기 내부 상태와 PPO 학습용 rollout은 유지한다.

Actor는 원 관측을 함께 입력받으므로 그래프 임베딩이 정책의 유일한 입력 병목이 되지 않는다. 행동 평균에 별도의 보정 출력을 더하는 잔차 구조나 게이트는 없다. Critic은 모든 비교군에서 현재 원 관측 10차원을 사용하는 공통 구조다. 보상·물리·센서·종료·행동 한계·PPO 손실은 기존 계약을 유지한다.

## 2. 현재 관측과 물리 좌표

현재 공통 관측의 순서와 생성식은 다음 파일이 기준이다.

- [vectorSchema.m](../src/simulations/+landing2d/+observation/vectorSchema.m)
- [toVector.m](../src/simulations/+landing2d/+observation/toVector.m)
- [staticContext.m](../src/simulations/+landing2d/+observation/staticContext.m)

부호 있는 정규화 함수를 다음과 같이 정의한다.

\[
B(x;s)=\frac{x}{|x|+s},\qquad s>0.
\]

공통 벡터의 실제 성분은 물리 값 자체가 아니라 다음의 정규화 값이다.

| 순서 | 정책 입력 | 원래 물리·관측 의미 |
|---:|---|---|
| 1 | \(B(e_x;s_x)\) | \(e_x=\hat x_G-\hat x_D\) |
| 2 | \(B(h;s_h)\) | \(h=\hat z_D-\hat z_{pad}\) |
| 3 | \(B(v_r;s_v)\) | \(v_r=\hat v_{G,x}-\hat v_{D,x}\) |
| 4 | \(B(\hat v_{G,x};s_v)\) | UGV 수평 속도 추정 |
| 5 | \(B(v_z;s_z)\) | 드론 수직 속도 |
| 6 | \(\sin\theta\) | 드론 피치의 사인 |
| 7 | \(\cos\theta\) | 드론 피치의 코사인 |
| 8 | \(B(q;s_q)\) | 드론 피치 각속도 |
| 9 | \(I_G\) | 현재 영상 측정 갱신 여부 |
| 10 | \(\tau_G/(\tau_G+s_\tau)\) | 마지막 영상 측정 갱신 후 경과시간; 미가용은 1 |

정규화 척도는 기존 정적 문맥과 환경 설정에서 가져온다. 현재 기본값은 수평 위치 3 m, 높이 8 m, 수평 속도 10 m/s, 수직 속도 1.5 m/s이며, 각속도와 경과시간 척도도 기존 설정을 사용한다.

드론 수평 속도는 별도 관측 성분이 아니다. 필요한 값은 \(\hat v_{D,x}=\hat v_{G,x}-v_r\)로 현재 입력의 대수 관계에서 계산한다. 보상의 참값 상태, KF 공분산, 미지 가속 또는 추가 항법 변수를 읽지 않는다.

### 2.1 정규화 역변환의 의미

\(|u|<1\)이면

\[
B^{-1}(u;s)=\frac{su}{1-|u|}.
\]

이 식 또는 동치인 안정적인 유리식으로 물리 단위의 조합을 계산한다. \(o_1-mo_2\)는 척도가 다른 정규화 좌표의 차이이므로 아래의 물리 접근 오차와 같지 않다.

물리 성분인 `[1:5,8]`의 정확한 `+1` 또는 `-1`은 역변환할 수 없는 입력으로 거부한다. 관측 경과시간 `o10=1`은 허용한다. 경계 오류를 실제 물리 값 0으로 대체하지 않는다.

### 2.2 추정값의 범위

UGV 추정이 초기화되지 않았을 때 기존 `toVector`는 1–4번 성분을 0으로 둔다. 그래프도 이 공통 입력만 사용한다. 이때 계산되는 작은 접촉 오차를 실제 접촉 안전의 확인으로 해석하지 않는다. 관측 갱신 상태는 이런 해석의 문맥이며 보정된 확률이 아니다.

## 3. 현재 접근 진행과 접촉 조건

기존 접근 목표는 [computeReward.m](../src/algorithms/+landing2d/+rl/computeReward.m)의 기울기를 그대로 사용한다.

\[
m=\tan(-\theta_C),\qquad h_+=\max(h,0),\qquad e_a=e_x-mh_+.
\]

현재 기본 카메라·접근 설정에서 \(m=\tan30^\circ\)이다. 고정된 패드 수직 위치를 가정한 접촉 전 비행에서

\[
v_a=\dot e_a=v_r-mv_z\quad(h>0)
\]

이고, 구현은 \(h\le0\)에서 \(e_a=e_x,\ v_a=v_r\)를 사용한다. \(h=0\)에서 \(h_+\)의 미분을 0으로 선택한 경계 관례다.

접근 진행 특징은

\[
\eta_a=e_av_a,\qquad \frac{d(e_a^2)}{dt}=2\eta_a
\]

이다. \(\eta_a<0\)이면 현재 접근 오차 제곱이 감소하고, 양수이면 증가한다. 현재 속도와 추정 상태로 얻는 순간 운동학적 지표이며, 실제 추정값 시계열을 차분한 결과나 미래 진행의 예측값은 아니다. 측정 갱신의 추정 보정까지 이 미분식이 설명하는 것은 아니다.

접근선의 정렬과 패드 수직 상방의 정렬은 다르다. 패드 정렬의 현재 변화는 \(e_xv_r\)로 설명할 수 있지만 이번 `ApproachSituation`의 세 번째 채널은 **\(e_av_a\)**다. 하강하는 동안 목표 접근 위치 \(mh_+\)도 바뀐다는 점을 반영한다.

기존 보상도 접근 위치·속도의 결합을 포함한다. 이번 특징은 새로운 보상 목표가 아니라, 기존 과제 목표에 부합하는 현재 정보를 정책 입력에서 명시하는 것이다.

## 4. 노드·특징·flatPhi 계약

각 노드의 처음 다섯 행은 수치 특징이며 여섯 번째 행은 노드 식별값 `노드 번호/7`이다. 사용하지 않는 수치 채널은 0으로 채운다. 순서는 `Q,R,V,A,P,C,L`이다.

| 번호·노드 | 수치 특징 1–5 | 역할 |
|---|---|---|
| 1. `ObservationQuality` (Q) | \([o_9,o_{10},0,0,0]\) | 현재 영상 측정 갱신 상태 |
| 2. `RelativeGeometry` (R) | \([o_1,o_2,0,0,0]\) | 상대 수평 위치와 높이 |
| 3. `MotionState` (V) | \([o_3,o_4,B(\hat v_{G,x}-v_r;10),o_5,0]\) | 상대·플랫폼·드론 수평 운동과 수직 운동 |
| 4. `AttitudeState` (A) | \([o_6,o_7,o_8,0,0]\) | 현재 자세와 각속도 |
| 5. `ApproachSituation` (P) | \([B(e_a;3),B(v_a;1),B(e_av_a;3),0,0]\) | 접근 오차·현재 변화율·현재 진행 방향 |
| 6. `ContactCondition` (C) | \([B(e_x;x_{tol}),B(v_r;v_{x,tol}),B(v_z;v_{z,tol}),B(\theta;\theta_{tol}),B(q;q_{tol})]\) | 기존 접촉 허용치에 비례한 현재 조건 |
| 7. `LandingContext` (L) | \([0,0,0,0,0]\) | 접근·접촉 정보를 결합하는 readout 위치 |

위 표는 현재 기본 설정의 수치를 표시한다. 접근 위치 척도는 기존 `relativePositionScale`, 접근 속도 척도는 기존 보상의 `targetRelativeSpeed`, 곱 척도는 두 값의 곱이다. 현재 단위와 값은 순서대로 3 m, 1 m/s, 3 m²/s다. 드론 수평 속도의 척도도 기존 `vxMax`를 사용한다. 실제 고정값은 `featureConstants`에 함께 보관한다.

세 번째 접근 채널은 `B(e_a;3)*B(v_a;1)`이 아니라 **`B(e_a*v_a;3)`**이다. 두 표현은 부호가 같아도 크기가 다르므로 혼용하지 않는다.

접촉 특징의 현재 기본 척도는 위치 0.5 m, 수평 속도 0.35 m/s, 수직 속도 0.30 m/s, 피치 5°, 각속도 10°/s이며, 실제 구현은 기존 환경의 해당 설정과 일치해야 한다. 피치는 현재 관측에서 \(\theta=\operatorname{atan2}(o_6,o_7)\)로 계산한다. 각도 척도는 계산 시 라디안으로 변환한다.

이 특징은 부호를 유지한다. 허용치 크기의 값은 \(|B|=0.5\)이며, 위반 정도를 모두 1로 잘라 같게 만들지 않는다. 특징값으로 행동을 차단하거나 접촉을 승인하지 않는다.

### 4.1 19차원 공정 대조 벡터

`flatPhi`는 위 표에서 실제로 사용하는 수치 채널을 Q→R→V→A→P→C 순서로 모은다.

\[
\begin{aligned}
\phi(o)=[&o_9,o_{10},o_1,o_2,o_3,o_4,
B(\hat v_{G,x}-v_r;10),o_5,o_6,o_7,o_8,\\
&B(e_a;3),B(v_a;1),B(e_av_a;3),\\
&B(e_x;x_{tol}),B(v_r;v_{x,tol}),B(v_z;v_{z,tol}),
B(\theta;\theta_{tol}),B(q;q_{tol})]^T.
\end{aligned}
\]

차원은 \(2+2+4+3+3+5=19\)다. 영 패딩, 상수 노드 ID 및 비어 있는 L의 수치 채널은 포함하지 않는다. 입력 위치 자체가 각 특징을 식별한다.

원 관측의 열 성분은 다음 위치에서 그대로 복원할 수 있다.

\[
o=\phi([3,4,5,6,8,9,10,11,1,2]).
\]

따라서 Semantic-MLP는 그래프에 제공되는 모든 변화하는 수치 특징과 원 관측 정보를 받는다. 그래프만 추가 파생 정보를 갖는 비교가 아니다. 이 정보 보존과 특징 배치의 일치는 수치 검사 대상이다.

## 5. 관계·경로·readout

| 의미 관계 | 간선 | 개수 |
|---|---|---:|
| `informsApproach` | R→P, V→P | 2 |
| `conditionsContact` | R→C, V→C, A→C | 3 |
| `qualifiesEstimate` | Q→P, Q→C | 2 |
| `informsLanding` | P→L, C→L | 2 |

의미 간선은 9개다. 노드마다 자기 연결을 하나 추가하므로 전체 간선은 **16개**다.

- Typed-RGAT: 의미 관계 4종 + 자기 연결 1종, 총 5종의 관계 파라미터.
- Untyped-GNN: 의미 관계를 1종으로 합침 + 자기 연결 1종, 총 2종의 관계 파라미터.
- 두 모델의 노드, 특징, 간선 양 끝점, 방향, 자기 연결 및 readout은 같다.
- 모든 관계는 같은 가산 집계 연산을 사용한다. 관계별 고정 곱셈 게이트·감독 규칙은 없다.

한 번의 메시지 전달로 P는 R/V/Q를, C는 R/V/A/Q를 결합한다. 두 번째 전달에서 L이 갱신된 P와 C를 받는다. 따라서 모든 물리·관측 노드는 두 홉 안에 L에 도달한다. 이 경로는 시간 간선이 아니라 현재 정보의 의존 관계다.

L은 처음에 수치 특징을 받지 않지만 노드 ID와 이웃 메시지를 받는다. 최종 그래프 표현은 \(g=H^{(2)}_{:,L}\)이다. 전체 노드 flatten 또는 가중합 readout이 아니다.

## 6. R-GAT 순전파와 공유 파라미터

배치 크기를 B, 노드 수를 N=7, 은닉 폭을 d=8이라 두면 \(X\in\mathbb R^{6\times7\times B}\)다. 첫 사영은

\[
H^{(0)}=\tanh(PX+b_P)
\]

이다. 간선 \(j\rightarrow i\)의 관계가 r일 때, 각 홉에서 다음을 계산한다.

\[
u_{ij}=W_rh_j+W_rh_i+b_a,
\]

\[
e_{ij}=a_s^T\operatorname{LeakyReLU}_{0.2}(u_{ij})+\beta_r,
\]

\[
\alpha_{ij}=\frac{\exp(e_{ij}-m_i)}{\sum_{k\in\mathcal N(i)}\exp(e_{ik}-m_i)},
\qquad m_i=\max_{k\in\mathcal N(i)}e_{ik},
\]

\[
h_i'=\tanh\left(W_0h_i+b+\sum_{j\in\mathcal N(i)}\alpha_{ij}W_rh_j\right).
\]

softmax는 관계별로 분리하지 않고 도착 노드의 모든 입력 간선에 적용한다. 자기 연결과 root 변환 \(W_0h_i\)가 모두 존재한다. 두 경로를 생략하거나 같은 것이라고 기술하지 않는다.

두 홉에서 \(W_r,a_s,b_a,\beta_r,W_0,b\)를 공유한다. 사영 P는 처음에 한 번 적용한다. 역전파는 두 홉에서 발생한 동일 파라미터의 기울기를 합산한다. 메시지를 제자리에서 순서대로 덮어쓰지 않고, 각 홉의 이전 H에서 모든 도착 노드를 동시에 갱신한다.

어텐션 벡터의 구현 저장 형식은 `[score(d), jointBias(d), relationBias(R)]`이며 학습 스칼라는 \(2d+R\)개다. 관계 이름은 연산 문자열로 추론되는 지식이 아니라 관계별 가중치 공유와 허용 경로를 지정하는 식별자다.

## 7. 네 Actor와 공통 Critic

| 비교군 | `encoderMode` | Actor 경로 | 인코더 파라미터 | Actor head | Critic | logσ | 총계 |
|---|---|---|---:|---:|---:|---:|---:|
| Raw-MLP | `baseline` | 10→110→2 | 0 | 1,432 | 661 | 2 | **2,095** |
| Semantic-MLP | `semantic_mlp` | 19→65→2 | 0 | 1,432 | 661 | 2 | **2,095** |
| Untyped-GNN | `untyped` | `[o10;g8]`→55→2 | 274 | 1,157 | 661 | 2 | **2,094** |
| Typed-RGAT | `rgat` | `[o10;g8]`→46→2 | 469 | 968 | 661 | 2 | **2,100** |

MLP의 은닉 활성 함수는 기존 tanh이며 출력 평균은 선형이다. 공통 Critic은 10→55→1이다. 공통은 입력·구조·학습 계약이 같다는 의미이며 서로 다른 방법의 학습 가중치를 공유하는 하나의 Critic이라는 뜻이 아니다.

전체 규모의 최대 차이는 6개, 최소 규모 대비 약 0.29%다. 사용하지 않는 파라미터를 채워 숫자를 일치시키지 않는다. 정확한 구성은 실행 등록 시 다시 산출한다.

### 7.1 파라미터 수 산식

입력 폭 6, 은닉 폭 d, 관계 수 R일 때 인코더 파라미터 수는

\[
\underbrace{6d+d}_{P,b_P}
+\underbrace{Rd^2}_{W_r}
+\underbrace{2d+R}_{a_s,b_a,\beta_r}
+\underbrace{d^2+d}_{W_0,b}
=(R+1)d^2+10d+R.
\]

따라서 d=8일 때 Typed(R=5)는 469개, Untyped(R=2)는 274개다. 두 홉은 파라미터를 공유하므로 이 수를 두 배로 세지 않는다.

입력 p→은닉 w→출력 2인 head는 \((p+3)w+2\)개다. 공통 Critic은 \(10\times55+55+55+1=661\)개이고, 상태 독립 행동 표준편차의 logσ 두 개를 전체에 포함한다.

### 7.2 학습 경로

Actor의 정책 손실이 `[o;g]` head와 R-GAT로 역전파된다. Critic은 원 관측 네트워크이므로 Critic 가치 손실이 Actor의 R-GAT에 직접 역전파되지 않는다. 보조 예측 손실·의미 라벨 손실·위험 제약 손실은 없다.

정책 평균, tanh 이전 표본, 정규화 행동, 실제 요청 가속도를 구분한다. 현재의 접근 진행 특징은 이미 실행한 행동이나 미래 행동의 입력이 아니며, 기존의 현재 속도에서 계산한다.

### 7.3 공통 API에서의 반환값

새 버전의 비기준 모델은 `current_semantics.encoderForward` 안에서 특징 인코더와 Actor head를 함께 계산해 완성된 2차원 평균을 반환한다. 공통 `agent.policy.mean`은 이 경우 파라미터 없는 항등 어댑터다. 따라서 호환용 `encoderSpec.graphDim=2`는 이 반환값의 폭이며, 내부 `LandingContext` 임베딩 폭은 8이다. Raw-MLP는 기존처럼 원 관측을 인코더 반환값으로 전달하고 별도 MLP에서 평균을 계산한다.

문서의 `[o10;g8]→MLP→μ2` 구조와 이 저장·호출 방식은 같은 계산이다. API 필드 이름을 근거로 임베딩이 2차원이라고 설명하지 않는다.

## 8. 유한성·정보 보존·미분 검증 명세

이 절은 검사해야 할 성질과 수학적 근거다. 실제 MATLAB 실행 결과는 별도의 검사 산출물로 기록한다. 명세에 적혀 있다는 사실을 검사 통과로 취급하지 않는다.

### 8.1 물리 조합의 안정적인 계산

\(u_k=o_k\), \(d_k=1-|u_k|>0\)라 두자. h>0에서 접근 오차의 분자·분모를

\[
N_e=s_xu_1d_2-ms_hu_2d_1,\qquad D_e=d_1d_2
\]

로 두면 \(e_a=N_e/D_e\)이다. 접근 속도는

\[
N_v=s_vu_3d_5-ms_zu_5d_3,\qquad D_v=d_3d_5
\]

이고 \(v_a=N_v/D_v\)다. h≤0에서는 상대 위치·상대 속도 각각의 분자·분모를 사용한다.

일반적으로 D>0일 때

\[
B(N/D;s)=\frac{N}{|N|+sD}.
\]

따라서 접근 진행 특징도

\[
B(e_av_a;3)=\frac{N_eN_v}{|N_eN_v|+3D_eD_v}
\]

로 계산할 수 있다. 이는 정규화된 값들의 잘못된 선형 조합이나 서로 다른 bounded 특징의 곱이 아니다. 공통 관측의 물리 척도를 보존하면서 취소 가능한 역변환 항을 제거한 식이다.

드론 수평 속도와 접촉 척도 재변환에도 같은 원리를 적용한다. 모든 보조 계산의 분모는 유효 입력 영역에서 양수여야 한다. 실제 정상화 척도에 대해 근접 경계 입력에서도 유한한 결과를 확인한다.

### 8.2 특징의 유한성

유효한 공통 관측과 양의 척도에서 모든 B 특징은 (-1,1), 갱신·경과시간은 [0,1], 자세 사인·코사인은 [-1,1]에 있다. 영 패딩과 유한한 ID를 포함한 X는 유한하다. 각 물리 성분의 정확한 포화, NaN, Inf는 입력 검증에서 구별한다.

KF 미초기화의 합법적인 영 입력, `visionAge=1`, 음의 높이, 상승·하강, 접근선 위·밖, 상대 속도 부호 반전의 예를 포함한다. 정확한 h=0과 atan2의 미정의 물리 입력을 일반적인 매끄러운 미분 검사 지점처럼 취급하지 않는다.

### 8.3 메시지 집계의 유한성

유한한 파라미터와 수치 연산 범위 안에서 tanh 사영은 유계다. 각 노드에 자기 연결이 있으므로 입력 간선 집합이 비지 않는다. 최대 점수를 뺀 softmax는 적어도 하나의 `exp(0)=1`을 포함하므로 분모가 양수이고, 각 도착 노드의 어텐션 합은 1이다.

이 성질은 임의로 큰 부동소수점 가중치의 오버플로를 보장해 막는다는 뜻이 아니다. 실제 순전파·손실·기울기의 `isfinite` 확인과 기존 기울기 제어를 유지한다.

## 9. 해석의 제한

현재 상대 속도가 작으면 현재 속도 정합 상태를 표현할 수 있지만 상대 속도 오차가 줄고 있다고 단정할 수 없다. 현재 하강은 제어명령이 아니라 운동 상태다. 그래프 경로는 실제 행동 연쇄가 아니다.

노드 특징·관계·readout은 사람이 정한 입력 구조이며, PPO는 그 구조 안의 파라미터를 학습한다. 관계 구조의 독립적 효용은 동일 정보의 Semantic-MLP와 같은 위상의 Untyped-GNN을 비교한 뒤 판단한다. 구현 검사·어텐션 변화·인코더 기울기만으로 성능 개선, 의미 이해 또는 안전성 보장을 주장하지 않는다.
