# v3.19 궤적 일관성·실행시간 검토

## 궤적 일관성 정의

정책 일관성은 같은 물리 조건과 외생 사건에서 paired sensor-noise 표본만 바꾸어 얻은 궤적 분산으로 평가한다.

- 위치 분산: 시간 정규화 pad-relative 궤적의 2차원 위치 분산
- 법선 분산: 카메라 접근 곡면에 수직인 방향의 분산
- along-track 분산: 접근 곡면 접선 방향의 분산
- 최종 상대 x 분산: 종료 시 $x_G-x_D$의 분산

표시용 왼쪽 궤적은 월드 절대좌표이고 metric 계산은 움직이는 착륙 지점을 기준으로 해야 하므로 pad-relative 좌표를 사용한다.

착륙 시간 분산은 0.108776 s²에서 0.709969 s²로 증가했다. v3.19는 공간 궤적을 강하게 모으지만 접지 시각까지 더 일정하다는 결과는 아니다.

## 실행시간

| 모델 | 파라미터 | Actor 추론 | 100 ms 정책 주기 점유 |
|---|---:|---:|---:|
| 일반 PPO | 6,101 | 0.069894 ms | 0.070% |
| v3.19 | 6,101 | 0.453968 ms | 0.454% |

v3.19 추론은 일반 PPO보다 느리지만 정책 주기 안에서 충분히 작다. MATLAB 측정값이며 하드웨어·JIT 상태에 따라 달라질 수 있다.

## 결론

v3.19의 근거는 held-out 임무 성능과 paired-noise 궤적 분산을 함께 만족한다는 점이다. 모든 개별 validation seed에서 분산이 항상 작거나, 다중 학습 seed 통계가 확립되었다고 주장하지 않는다.
