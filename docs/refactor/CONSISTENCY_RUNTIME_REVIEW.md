# 일관성·실행시간 검토

## 정의

- `C_valid`: 독립 물리 판정기의 허용 행동 집합에 정책 명령이 속하는 비율, 높을수록 우수
- `D_obs`: 동일 외생 궤적에서 센서 잡음 변화 전후의 행동 거리, 낮을수록 우수
- `J_policy`: 정상 외생 구간에서 요청 명령 변화율의 시간 가중 RMS, 낮을수록 우수

## 결론

온톨로지 구조는 허용 행동 일관성을 높였으나 작은 관측 변화와 시간 변화에 대한 출력 평활성은 일반 PPO보다 낮음. 따라서 해석 가능성·구조화와 전 지표 일관성 우월성을 동일시하지 않음.
