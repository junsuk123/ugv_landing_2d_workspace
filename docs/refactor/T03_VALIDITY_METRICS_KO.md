## 1. 독립 유효 판정기

```text
landing2d.metrics.behaviorValidity(probe, requested_action, config)
  -> valid, applicable, context_id, constraint_margins, reason_codes
```

### 1.1 예측

- 입력: probe의 참값 드론·패드 상태(평가 전용), 기준 관측(배율 0)의 결정 문맥, 감독기 적용 전 요청 명령
- 방법: 요청 명령을 horizon 동안 고정, 기존 `stepPlanar`로 적분, 기존 `evaluateTermination`으로 첫 사건 분류
- 패드: 현재 속도로 등속 이동 (보이지 않는 미래 가속 미가정)
- 감독기: 적용하지 않음 (요청 명령 자체를 판정, 교정 없음)
- 상태: 복사본, 에피소드에 되먹임 없음

### 1.2 허용 집합

| 규칙 | 조건 (여유 ≥ 0이면 만족) | 적용 범위 |
|---|---|---|
| 안전 접촉 | 비승인·패드 이탈·과속·자세 한계 접촉, 안전 범위 위반 없음 | 항상 |
| 제동 여유 | horizon 끝 고도 − 접지 고도 − 접지 속도까지 감속 거리(응답 지연 포함) | 항상 |
| 시야 유지 | horizon 동안 패드 중심 FOV 여유 최소값 | 영상 최근, 패드 현재 시야 안, 최종 하강 해제 고도(0.7 m) 위, 안전한 격자 명령 중 유지 가능한 것이 있을 때 |
| 수평 추종 후퇴 | 상대 수평 속도(고도 > 0.7 m) 또는 패드 중심 정지점 오차(≤ 0.7 m)가 최선 + kappa × 도달 범위 이하 | 영상 최근 |
| 수직 접근 후퇴 | horizon 끝 고도가 최선 + kappa × 도달 범위 이하 | 착륙 승인 + 영상 최근 |

- 도달 범위: 같은 상태에서 안전한 행동 격자(7 × 7)가 내는 값의 최소–최대
- 집합 성질: 격자의 일부만 허용, 상승·하강·가속 방향 자체를 정답으로 두지 않음, 착륙 금지·복구 요청·영상 단절 문맥에서는 수직 접근 규칙 없음
- 적용 제외: 감독기 복구 비행(`supervisor_override`, 정책 명령이 무시됨), 안전한 격자 명령 없음(`no_safe_action`)
- 위반 사유: `unsafe_contact`, `unauthorized_contact`, `missed_pad_contact`, `envelope_violation`, `braking_margin`, `fov_loss`, `tracking_regression`, `approach_regression`
- 문맥 식별자: `영상/고도/결정` (fresh·recent·stale·none / final·low·high / authorized·inhibited·abort), 기준 관측과 자기 고도에서만 계산

## 2. horizon·kappa 동결 (validation 전용)

- 후보: horizon 0.3·0.5·1.0·1.5·2.0 s, kappa 0.25·0.5·0.75
- 기준 (비교군 출력 미사용):
  - 적용 가능 probe 비율 ≥ 0.90
  - 잡음 없는 인과적 기준 구동기 명령의 유효 비율 ≥ 0.95 (유능한 제어기를 무효로 모는 판정기 배제)

- test: 동결값만 사용(2,410 probe), `prepareProbes`가 validation → 동결 → test 순서 강제

## 3. 지표

| 지표 | 정의 | 집계 | 방향 |
|---|---|---|---|
| C_valid | 100 × mean(valid_ref ∧ valid_pert), 적용 가능 probe | 문맥별 계산 후 문맥 동일 가중 평균(문맥 최소 10 probe), 기준 유효율·적용 수·제외율 병기 | 높을수록 |
| D_obs | ‖u01_ref − u01_pert‖ / √2, u01 = (a − a_min)/(a_max − a_min) | 동일 문맥 probe(관측 신뢰도·안전 판단 경계가 기준과 같음) 평균·P95 | 낮을수록 |
| D_seed | 같은 probe에서 서로 다른 학습 시드 정책 명령의 정규화 거리 | 시드쌍 평균, 시드 삭제 잭나이프 표준오차(≥ 3 시드), 교란군은 그래프 시드별 후 요약, 시드 < 2이면 NaN | 낮을수록 |
| J_policy | 요청 명령 변화율의 시간 가중 RMS, 실제 정책 타임스탬프 | 외생 일정만으로 정한 정상 구간(시작 1 s, UGV 가속 구간, dropout, pitch 외란과 각 2 s settling 제외, 1 s 이상) 안에서만 차분, 구간 연결 없음, 감독기 적용 명령 저크 병기 | 낮을수록 |

- 기준 관측: 같은 상태·같은 측정 이력의 배율 0 관측
- 구현: `landing2d.consistency.probeValidity`, `probeMetrics`, `seedDivergence`, `steadyWindows`, `policyJerk`, 학습된 실행 평가 `evaluateRuns`(고정 probe)·`closedLoopJerk`(폐루프, probe 은행과 같은 분할 시드)
- J_policy 에피소드 통합: 에피소드별 RMS를 차분 구간 길이로 가중해 sqrt(Σ J²·w / Σ w), 에피소드 평균·중앙값 병기
- J_applied: 물리 스텝(0.01 s) 차분이라 결정 주기(0.1 s) 영차 유지의 계단 변화만으로 J_policy의 약 √10배 → 비교군 간 비교에만 사용, J_policy와 직접 비교 금지

## 4. 검증 (MATLAB R2025b 실제 실행)

- self-test 13개 통과, 신규 `behavior-validity`:
  - 복구 비행 문맥 적용 제외와 사유
  - 승인·영상 최근·정상 추종: 허용 비율 5–95%, 최대 상승 무효(`approach_regression`), 최대 전진 무효(`tracking_regression`), 완만한 하강 유효, 명령과 무관한 문맥 식별자
  - 착륙 금지·영상 단절: 상승·정지 모두 유효
  - 저고도 고속 하강 중 착륙 금지: 하강 지속 무효, 상승 유효
  - test 분할 동결 거부

## 5. 한계

- 상수 정지 명령: 순간 판정으로는 대부분 허용(C_valid 99.7, D_obs 0, J_policy 0) → 착륙하지 못하는 정책을 일관성 지표만으로 구별 불가
- 보고 규칙 (T05 적용): 일관성 우위(C_valid·D_obs·D_seed·J_policy)는 착륙 성공률이 사전 정한 허용 저하 폭 안인 비교군끼리만 주장, 상수 정지·최대 상승 등을 음성 대조로 같은 표에 병기, C_valid 단독 보고 금지
- kappa: 상태 다양화 잡음 없는 기준 구동기도 0.5에서 유효율이 낮아 관대한 값(0.75)이 선택될 수 있음

### 7.5 후속 조치 (사용자 결정, 2026-10-08)

- 관계 교란 RGAT PPO 공식 비교군 제외: 공식 비교군은 일반 PPO·온톨로지-RGAT PPO 두 개 (`methodRegistry.methods`), 관계 교란은 `registry.ablations`의 절제 실험으로만 유지(id를 명시하면 `applyMethod`·`trainCampaign`·`evaluateRuns`·`closedLoopJerk` 사용 가능), 비교 그림은 비교군 수에 맞춤
