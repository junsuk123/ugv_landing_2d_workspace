# 일반화 목표 재개 — 후보 C2: 기본·보정 용량 재배치 (relational_residual_v7, 2026-10-27)

## 위치와 근거

[C1](RELATIONAL_RESIDUAL_V6_KO.md)은 개발 기준에서 실패했고 확인은 열지 않았다. C1에서 학습 기준은 통과했지만, TOSM의 OOD 착륙률(88.67%)이 PPO(91.27%), Residual-MLP(90.33%), Shuffled(88.87%)보다 모두 낮았다. motion·noise 강인성 기준도 실패했다.

Codex는 C1 결과를 판정한 뒤 GO를 냈다([decisionP.yaml](../results/relational_residual_v6/post_hoc/decisionP.yaml)). C2는 목표 재개 계획에 이미 등록된 두 번째이자 마지막 후보이고, **정의를 바꾸지 않고** 실행한다.

목표, 완료 판정, 권한은 C1 문서와 같다.
- 확인 실험에서 TOSM−PPO와 TOSM−Shuffled의 보정 구간 하한이 모두 0보다 커야 한다.
- motion·noise에서 착륙·위험·추종 평균이 악화되지 않아야 한다.
- 전체 검산을 통과해야 한다.

달성은 보장되지 않는다.

## 가설과 변경

v5에서는 원 관측 기본 MLP(10→74→2)가 행동의 주 경로이고, 관계 보정은 작은 잔차에 머문다. C2는 기본 경로의 용량을 줄이고 그 몫을 보정 경로로 옮긴다. 이렇게 하면 관계 배치가 행동에 미치는 기능적 몫이 늘어나는지 시험한다. 원인을 단정하지 않으며, 그래프 폭 증가만의 효과나 같은 표현 능력을 주장하지 않는다.

**변경:** v5 기반이다. tanh를 유지하고 C1의 φ는 결합하지 않는다.

| 항목 | v5 | C2 |
|---|---|---|
| 세 잔차 방법의 기본 MLP 폭 | 74 | 42 |
| 그래프 노드 폭 (TOSM·Shuffled) | 8 | 12 |
| Residual-MLP 보정 폭 | 36 | 68 |

**바뀌지 않는 것**
- PPO(Actor 10→110→2, Critic 10→55→1)
- 공통 raw Critic, attention 수식, 4노드·10간선·3관계 위상, 두 홉, 전체 노드 readout
- 행동 tanh, 관측 변환
- 물리·센서·10차원 관측·reward_v5·행동·종료·PPO 손실·학습 분포(a2 0.3–0.8)·학습률·탐색·750×6 상한·validation 규칙

**초기화:** v5와 같은 생성 규칙에서 폭만 바꾼다. 결과적으로 v5와 같은 초기 모델은 아니다.
- 노드별 P: randn/√fan-in
- W: randn/√h. 두 의미 관계는 공통 초기값 (U1+U2)/√2를 쓴다.
- a = [randn(1,h)/√h, 0(1,h+3)]
- W0: randn/√h
- R: 난수를 뽑은 뒤 0을 넣는다. br = 0, β = −2.
- MLP F: randn/√10
- 기본 MLP: mlpInit([10 42 2], 0.1)
- 난수 호출 순서는 v5와 같다. 폭을 74/8/36으로 두면 v5 인코더를 정확히 재현한다(selfTest).

**파라미터 수**

| 방법 | 기본 MLP | 보정 경로 | Critic | logσ | 합계 |
|---|---|---|---|---|---|
| PPO | — | — | — | — | 2,095 (불변) |
| Residual-MLP | 13·42+2 = 548 | 13·68+3 = 887 | 661 | 2 | 2,098 |
| TOSM·Shuffled | 548 | 4h²+25h+6 = 882 (h = 12) | 661 | 2 | 2,093 |

최대 차이는 0.24%다.

**구현**
- `landing2d.residual_context.capacityEncoderInit`
- `graphState.basePolicyHiddenSizes=42`, `hiddenDim=12`, `correctionHiddenSize=68`
- 검증기는 v5 묶음(74/8)과 C2 묶음(42/12/68, φ 없음, v5 위상)만 허용하고, 섞인 조합은 거부한다.
- `residual_motion.encoderForward`·`encoderBackward`의 노드 폭은 `spec.hiddenDim`에서 읽는다. v3–v6에서는 8이다.
- 알고리즘 `relational-residual-v7.0`, 패키지 `landing2d.residual_capacity`, 출력 `results/relational_residual_v7/`
- 공개 진입점은 v5 재현 경로를 유지한다.

**공정성:** 세 잔차 방법을 같이 바꾼다. Shuffled는 v5 규칙을 따른다(위상·self·유형 수 2/4/4 보존, 의미 간선 6개 중 4개 교란, graphSeed = trainSeed). 결과를 보고 배치를 고르지 않는다. 네 방법 모두 새로 학습한다.

**예상 실패 양상**
- 기본 경로 축소로 학습이 느려지거나 불안정해진다.
- 보정 몫이 늘어도 관계 타입끼리 서로 대체한다.
- 혼합 계수가 작은 채로 남는다.
- 잡음 증폭이 생긴다.

## 개발 (프로토콜 v2)

- 461–465 × 네 방법, 모두 새로 학습한다. 등록 전 미사용을 다시 감사한다.
- 평가: 가속 1.5–2.0 m/s², 누락 2.1–2.9 s, 잡음 ×3, 환경 9001–9100에서 12,000회.
- 개발 기준은 C1과 같다(`landing2d.residual_soft.developmentGate`, v5 규칙).
  - 네 방법 모두 Reached80과 선택 validation ≥ 80%가 5/5다.
  - TOSM validation 중앙값이 PPO·MLP − 5%p 이상이고, 위험 중앙값이 +2%p 이하다.
  - 세 OOD 평균 차이가 모두 양수다.
  - motion·noise 평균 방향 기준을 만족한다(허용 오차 1e−12).
  - 세 개별 98.3333% 짝 t 구간(df = 4)은 보고만 한다.
- 출력 해시는 execution.json을 최종화한 뒤 수집한다(C1 기록 순서 결함 보완).

## 확인 (개발 통과 시에만, 별도 등록 뒤)

C1 계획과 같다.
- 431–450 × 네 방법을 새로 학습하고, validation으로만 선택한 뒤 잠근다.

## 예산과 중단 규칙

- C2는 마지막 등록 후보다. C2 개발이 실패하거나 확인이 실패하면 "등록 예산 내 목표 미달성"으로 종료한다.
- 시드 제외·재학습·예산 연장·기준 완화·확인 표본 재사용·추가 후보는 없다.
- 관측·센서·보상·PPO 목적·학습 분포 변경, 평가 재보정, 후보·예산 확대, 추가 확인 회차는 사용자 승인이 필요하다.

## 주장 범위

- 개발 통과·응답 증가·관계 민감도 증가만으로 일반화 우위를 주장하지 않는다.
