# 학습 가속 범위 확대 R1 — 사전 등록 (2026-10-26)

[수평 이득 감사](CONTROL_GAIN_AUDIT_KO.md)에서 네 방법에 공통인 미지 가속 과소 반응과, 반응성과 잡음 강인성 사이의 상충을 확인했다. 이 실험은 가설 2를 검증한다. 학습 UGV 가속 범위만 넓혔을 때 미지 가속 대응이 바뀌는지, 그리고 그 대가가 있는지 본다.

- **승인:** 사용자 "진행해"(2026-10-26). 범위는 이 등록 실험 1회, 새 학습 20모델이다.
- **설계·기준:** Codex 읽기 전용 판단(GO)으로 학습 전에 고정했다.
- **고정:** 일반화 목표의 [미달성 종료](GENERALIZATION_GOAL_CLOSURE_KO.md), 확인 환경 9101–9200, 예약 확인 시드는 그대로 둔다.

## 질문

학습 에피소드의 CA 가속 범위만 넓히면 다음이 어떻게 되는가?
1. 기존 미지 가속(1.5–2.0 m/s²)의 착륙 성능이 개선되는가?
2. 개선이 네 방법에 공통인가?
3. ID·잡음·누락 성능에 대가가 있는가?

## 설계

| 항목 | 내용 |
|---|---|
| 독립 변수 | 학습 CA `a2Range` [0.3, 0.8] → **[0.3, 1.4]** m/s². 균등 표집은 그대로다. 같은 에피소드 시드에서 CV/CA 패턴은 같고, a2만 같은 난수를 넓은 범위로 사상한다(첫 60개 에피소드에서 확인). |
| 고정 | CV 확률 0.5, T1·T2·초기 조건, 물리·센서·10차원 관측·reward_v5·행동·모델·초기화·PPO·750×6 상한 |
| validation | 체크포인트 선택은 v5 분포([0.3, 0.8], 시드 2001–2200)에 고정한다(`experiment.validationScenario`). |
| 방법·시드 | PPO, Residual-MLP, TOSM, Shuffled × **421–425**, 모두 처음부터 학습한다. 같은 방법·시드의 v5 모델이 짝 대조군이다. |
| 평가 | 프로토콜 v2의 6셀을 **v5 환경**(학습 분포를 상속하지 않음)에서 평가한다. 개발 환경 9001–9100, 셀당 100회 × 20모델 = 12,000회다. 저장된 v5 원자료와 에피소드 단위로 짝짓는다. |
| 산출물 | `results/acceleration_range_r1_v1/`, 모듈 `landing2d.accel_range` |

v2의 motion OOD(1.5–2.0)는 새 학습 상한 1.4보다 크므로 그대로 OOD다. v1 motion OOD(1.0–1.5)의 대부분은 새 학습 범위 안에 들어간다.

## 공통 코드 변경

`landing2d.rl.ppoTrain`에 `experiment.validationScenario`가 있으면 validation 에피소드에만 그 시나리오를 쓰는 분기를 추가했다. 필드가 없으면 기존 경로와 같다. v5 설정에서 네 방법 1 update smoke의 agent와 history(wallSeconds 제외)가 변경 전과 비트 단위로 같았다.

## 학습 전 검사 (TEST ONLY)

`landing2d.accel_range.checkSetup`으로 다음을 확인했다.
- 9101–9200 설정 거부
- v5와의 설정 차이는 a2Range·validationScenario·출력 폴더뿐
- 학습 서명이 v5와 달라 체크포인트를 재사용하지 않고, 새 체크포인트도 아직 없음
- 초기 agent 20개가 v5와 같음
- 학습 시나리오 a2 최대 1.40, CA 중 0.8 초과 비율 52%
- 첫 validation 행이 v5와 같음(4방법)
- 평가 셀 120개가 v5와 같음
- v5 체크포인트를 새 평가 경로로 돌려 저장 v2 에피소드 24개를 재현
- 판정 네 갈래 합성 검사

## 사전 등록 기준

Δ = 새 모델 − v5를 에피소드 짝마다 구한다. S = 착륙률, U = 위험 접촉률이고 단위는 %p다. 집계는 다음 순서로 한다.
1. 모델별로 환경 100개를 평균한다.
2. 같은 시드의 네 방법을 동등 평균해 시드 블록을 만든다. 시드 블록 5개가 추론 단위다.
3. 시드 블록으로 양측 t 구간(df = 4)을 구한다.

| 기준 | 규칙 |
|---|---|
| L 학습 | 네 방법 각각 Reached80과 선택 validation 착륙률 ≥ 80%를 5/5 시드에서 충족한다. 실패 시드도 보존하고 보고한다. |
| G 평균 개선 | motion OOD 시드 블록 평균 ΔS ≥ +5%p이고 95% 하한 > 0 |
| K 공통 개선 | G를 충족하고, 네 방법 각각의 motion OOD ΔS 95% 하한 > 0 |
| N 비열등 | 네 방법 각각, 6셀 모두에서 ΔS 95% 하한 ≥ −2%p이고 ΔU 95% 상한 ≤ +2%p |
| H 대가 | 시드 블록에서 noise 또는 dropout OOD가 다음 중 하나를 만족한다(네 비교 각각 98.75% 구간). ① ΔS ≤ −5%p이고 상한 < 0. ② ΔU ≥ +2%p이고 하한 > 0. |

판정은 다음과 같이 정한다.
- L 미달 → `training_failure`. 효과 추정은 보고하되 대체 학습은 하지 않는다.
- L·G·H → `trade_off_supported`
- L·G·N → `improved_within_registered_margins`
- L·G만 → `gain_with_unresolved_risk`
- G 미달 → `insufficient_evidence_of_improvement`. 무효과를 입증한 것은 아니다.

"네 방법 공통 개선"이라는 표현은 K를 충족할 때만 쓴다. 어떤 판정도 TOSM 우위나 종료된 일반화 목표의 달성을 뜻하지 않는다. aim RMS, 비행시간, 명령 변화율, 실패 유형, OOD−ID 변화는 보조 지표이고 주 판정을 뒤집지 않는다.

## 교란과 한계 (사전 기록)

- 같은 시드여도 학습 궤적이 달라진 뒤의 PPO 난수 소비는 v5와 같다고 보장하지 않는다.
- 범위를 넓히면 평균 가속과 기존 구간의 표집 비중도 함께 바뀐다. 범위 상한만의 효과로 해석하지 않는다.
- 이미 쓴 개발 시드와 환경에서 하는 후속 탐색이다. 확인 근거가 아니다.
- 착륙 개선만으로 가속 추정 능력이나 수평 이득이 회복됐다고 단정하지 않는다.
