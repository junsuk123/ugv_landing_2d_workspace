# 관계 잔차 구조: 단계별 재구성 (2026-10-25)

사용자가 제공한 설계안을 반영한 개발 후보다. **2026-10-26: 시드 341–345의 20개 모델·12,000개 고정 평가를 완료했으나 개발 기준에 실패해 성능 개선안으로 채택하지 않는다.** 아래 수식과 조건은 해당 실험의 재현 계약이다. 기존 2D 동역학·센서·reward_v5·행동·종료·PPO 목적함수·학습 분포와 검증 일정을 유지한다. 과거 모델과 결과는 재현용으로 보존한다.

## 근거와 이번 변경

v3.2의 새 개발 시드 291–295에서 TOSM은 4/5만 학습했고 PPO와 Shuffled는 5/5였다. 9,000개 평가의 OOD 착륙률은 각각 78.60%, 98.07%, 96.33%였다. 실패 시드 294의 고정 validation 재생에서는 지면 가까이에서 추종·하강 응답이 부족했다. 이 관찰은 병목이 원인임을 확정하지는 않지만, 정책 전체가 한 종착 노드 표현에 의존하는 구조를 다시 검토할 근거다.

이번 단계는 다음 세 요소를 함께 적용한 구조 후보를 검사한다.

1. 모든 관측을 받는 벡터 base와 작은 초기 잔차 보정 경로.
2. 한 종착 노드 대신 네 노드 전체를 읽는 그래프 표현.
3. 모든 비교군에 동일한 벡터 Critic. Critic 인코더는 없다.

각 변경의 독립 효과는 이 비교만으로 주장하지 않는다. 관계 구조의 추가 효과는 동일한 잔차 결합을 쓰는 MLP 및 관계 교란 비교군으로 검사한다.

## 입력과 수식

현재의 동일한 10차원 센서 관측 o를 그대로 모든 방법에 제공한다. 새 참값·미래 정보·추정기 메타데이터를 추가하지 않는다. Q={updated, age}, T={target vx}, U={vz, sinθ, cosθ, pitchRate}, R={relative x, height, relative vx}의 네 노드를 유지한다.

노드별 입력 크기에 맞는 사영을 사용한다. 사영 폭은 8이고, 각 노드에 독립 bias가 있다. 두 홉의 가중치를 공유하며, 각 홉의 source evidence는 최초 사영 H0, query는 이전 홉 H다. 관계 연산은 v3.2/v3.3의 검증된 dynamic attention을 재사용한다. 의미 관계 W1/W2는 같은 값으로 시작하지만 별개 파라미터로 학습된다.

\[
b=\tanh(P_b o+b_b),\qquad
c=\tanh(R[H_Q;H_T;H_U;H_R]+b_r),
\]
\[
z=\operatorname{LayerNorm}(b+\sigma(\beta)c),\quad \beta_0=-2.
\]

b,c,z의 폭은 16, LayerNorm epsilon은 1e-5다. Actor는 z→16→2, Critic은 o→55→1이다. MLP 보정 비교군의 c는 10→34→16의 MLP로 바꾼다. 원래 관측이 그래프를 거치지 않고 Actor에 도달하는 경로를 확보한다는 뜻이며, 학습된 base나 LayerNorm이 정보를 수학적으로 완전 보존한다는 주장은 아니다. 잔차 계수는 세 잔차 비교군에 공통이며, 신뢰도나 인과적 중요도 지표로 해석하지 않는다.

## 비교군과 공정성

|방법|Actor 표현|Critic|총 학습 파라미터|
|---|---|---|---:|
|PPO|10→110→2|10→55→1|2,095|
|Residual-MLP PPO|공통 base + MLP 보정|동일|2,112|
|TOSM residual PPO|공통 base + 관계 그래프 보정|동일|2,101|
|Shuffled residual PPO|공통 base + 교란 그래프 보정|동일|2,101|

수에는 행동 logσ 2개가 포함된다. 최대 용량 차이는 0.82% 미만이며 쓰이지 않는 파라미터를 채워 정확한 수를 맞추지 않는다. 일반 PPO를 유지한다. 새로운 용량에 맞춰 모든 방법을 새로 학습한다. 기존의 1,419개 모델을 새 비교에 섞지 않는다.

Actor의 head와 인코더를 합친 한 기울기 노름으로 clipping하고, 모든 Actor 파라미터에 공통 학습률 2e-4를 적용한다. Critic 학습률 5e-4와 PPO 손실은 유지한다. 이 optimizer 변경은 새 버전에만 적용한다. 세 잔차 방법의 base·head 초기값은 같고, 네 방법의 Critic 초기값은 같다. 정책에 따라 이후 수집 궤적이 달라지므로 Critic 학습값과 advantage가 같아진다는 뜻은 아니다.

관계 교란은 기존 7간선의 위상·self·관계별 개수를 유지하면서 세 의미 간선 중 두 개의 유형을 바꾼다. T→R와 U→R가 공유하던 informsMotion 파라미터의 공유 쌍이 바뀌므로 단순한 관계 이름 교환이 아니다. 첨부안의 단일 T→R 유형과 단일 U→R 유형만 교환하는 방식은 자유롭게 학습하는 행렬의 이름 교환에 해당하므로 채택하지 않는다.

## 후속 단계로 분리한 제안

- NIS와 공분산은 유용한 후보지만, NIS는 실제 가속이나 모델 오차에도 커진다. 이를 무조건 낮은 신뢰도로 취급하는 단조 감쇠는 급변 추종을 막을 수 있다. 다음 단계에서 관측 가능한 메타데이터의 정의와 공통 입력 추가 효과를 분리한다.
- own vx 재구성은 정규화된 두 속도의 단순 차가 아니다. 현 정규화가 x/(|x|+s)이므로 물리 단위로 역변환 후 빼고 다시 정규화해야 한다. 이번 단계는 입력 변경 자체를 추가하지 않는다.
- 동역학 보조 손실은 PPO 목적의 변경이므로 별도 단계에서 모든 비교군에 같은 학습 표적과 가중치로 제공한다. 미래 표적은 학습용이며 정책 입력이 아니다. 이번 후보에는 없다.
- 첨부안의 291–295는 이미 사용한 개발 시드다. 새 개발 341–345, 미사용 확인 예약 351–360을 사용한다.

## 개발과 확인

개발 전에 소스·설정·게이트를 등록한다. 구조/미분/실제 PPO 갱신/기존 버전 회귀를 통과해야 본 학습한다. 개발은 5시드×4방법, 각 750 update×6 episode 상한과 기존 validation 선별·plateau 종료를 유지한다. 네 방법 모두 4/5 이상에서 validation 80% 도달 및 선택 모델 80% 이상, TOSM의 선택 validation 중앙값이 PPO와 Residual-MLP 각각보다 5%p 넘게 낮지 않고 unsafe 중앙값이 2%p 넘게 높지 않아야 한다. 이것만으로 일반화 우위를 주장하지 않는다.

고정된 motion/dropout/noise ID/OOD 평가(조건당 100 episode, 개발 9001–9100)를 네 방법에 동일하게 실시한다. 개발 결과는 원인 분석과 다음 후보 개발용이다. 확인을 열기 전 TOSM의 OOD 평균 성공률이 세 비교군보다 각각 높고, noise/motion 성공률·위험 접촉·추종 오차의 평균 방향도 각각 악화하지 않아야 한다. 시드별 결과와 불확실성 구간을 모두 기록한다.

확인 351–360과 환경 9101–9200은 개발 완료 후 별도 소스 고정 전까지 실행하지 않는다. 확인의 세 주 비교는 TOSM−PPO, TOSM−Residual-MLP, TOSM−Shuffled이며 기존 목표의 순차 확인 alpha 예산을 세 비교로 나눈다. 첫 확인 family alpha=.025이면 각 양측 구간은 99.1667%다. 세 하한이 0보다 커야 세 비교에 대한 우위를 주장한다. 안전·오차와 조건별 결과를 함께 보고한다. 실패한 시드·버전·구간은 삭제하지 않는다.

진행 중이던 v3.3은 원래 등록 조건대로 마무리한다. 새 설계는 진행 중 실험의 216개 등록 파일을 변경하지 않는 새 namespace와 임시 통합 overlay에서 검증하며, 기존 실험의 종료·검산 후 공통 경로에 반영한다.

## 다음 후보: 행동 평균에 관계 보정 직접 결합

v1은 원 관측 경로가 있어도 `10→16 base→LayerNorm→16→2` 공통 경로를 반드시 통과한다. 다음 후보 `relational_residual_v2`는 표준 MLP 기본 정책을 직접 출력에 연결한다.

\[
\mu(o)=B_2\tanh(B_1o+b_1)+b_2+\sigma(\beta)\tanh(R e(o)+b_r).
\]

기본 정책은 10→74→2이고, 그래프 보정은 기존 4노드·7간선·폭 8·두 홉·모든 노드 readout을 사용한다. MLP 보정은 10→36→2다. 기본 경로에 LayerNorm이나 공통 특징 head가 없다. 마지막 층 초기화 gain은 0.1, beta 초기값은 −2이며, 네 비교군의 공통 벡터 Critic·PPO 손실·joint actor clipping·학습률·환경·관측·보상·행동을 유지한다. 총 파라미터는 PPO 2,095, MLP 2,098, 그래프 각각 2,089다.

보정을 0으로 둔 함수와 기본 정책의 함수가 정확히 같고, 고정된 상류 기울기에서 기본 정책 미분도 같다. 학습 중 상류 기울기·방문 상태까지 동일하다는 뜻은 아니다. 기본 폭 확대와 결합 위치 변경을 함께 적용하므로 이후 결과만으로 LayerNorm 하나를 원인으로 지목하지 않는다.

별도 prototype에서 모든 파라미터/입력 미분, 실제 PPO 미분, 네 방법 1 update, 저장·복원, 8개 라이브 재생, 기존 13+14+13 회귀 검사와 PPO 수치 일치를 확인했다. 근거는 `results/goal_generalization_20261025/logit_prototype_checks.mat`·`logit_integration_checks.mat`다. 이 문단은 prototype 단계 기록이다. 이후 [정식 v2 통합 및 검증](RELATIONAL_RESIDUAL_V2_KO.md)을 완료했으며, 새 본 학습은 v2의 별도 등록 계약을 따른다.

새 개발은 미사용 361–365×네 방법을 모두 새로 학습한다. 시드 343 하나에 맞춘 수정의 재시험으로 충분하다고 보지 않는다. 확인은 미사용 371–380을 예약하고 이전 351–360은 미사용 상태로 남긴다. 본 학습 전 최종 코드·문서·실행 스크립트를 별도로 등록한다. 다음 후보의 학습 안정성 게이트는 네 방법 모두 Reached80·선택 검증 80% 이상 **5/5**로 강화한다. 세 양의 OOD 평균 차이, motion·noise의 착륙·위험 접촉·aim RMS 평균 방향 규칙과 미사용 확인 요건은 유지한다. NIS/공분산·좌표 재배치·보조 손실은 이 후보에도 함께 넣지 않는다.
