# 강화학습 귀납적 편향 진단 v1 (2026-10-26)

동결된 v5 개발 정책(학습 시드 421–425 × PPO·Residual-MLP·TOSM·Shuffled, 20개)으로 네 가지 가정과 관계 구조의 기여를 분리했다. 새 학습, 보상 수정, 확인 환경 9101–9200 사용, 기존 결과 덮어쓰기, 시드 제외, 커밋은 하지 않았다. 일반화 목표는 [미달성 종료](GENERALIZATION_GOAL_CLOSURE_KO.md) 상태를 유지한다.

## 요약

1. **네 방법은 사실상 같은 제어기를 학습했다.**
   - 입력별 행동 민감도 구성이 같다. a_x는 상대 위치·고도·상대속도에 반응하고 UGV 절대속도에는 거의 반응하지 않는다.
   - 물리적 관측 변화에 대한 응답 크기는 10% 이내로 같다.
   - 상태 유사성(Q1)과 행동 위상(Q4)에서 TOSM을 구별할 만한 차이가 없다.
2. **공통 병목은 미지 가속에 대한 과소 반응이다(Q2).**
   - 모든 정책의 응답 방향은 기준 구동기와 99–100% 같다.
   - 크기는 UGV 속도 응답이 기준의 약 0.22배, 위치 응답이 약 0.16배다.
   - v2 미지 가속(UGV 1.5–2.0 m/s²) 동안 평균 요청 가속은 0.39–0.40 m/s²다.
   - 짝지은 분기 롤아웃에서 a_x를 +0.25 더 주면 네 방법 모두 return·착륙률·aim이 좋아졌다. 정책 자신의 행동이 최선이었던 경우는 16–38%다.
3. **보상은 희소하지 않다(Q3).**
   - 단계 보상의 대부분은 readiness 차분과 퍼텐셜 shaping이다.
   - 제어 비용은 결정당 약 1e−5로 사실상 0이다. 과소 반응을 행동 벌점으로 설명할 수 없다.
4. **행동은 부드럽지만 운동 대응이 부족하다(Q4).**
   - 포화 0%, 감독기 수정 0, 명령 변화율 0.6–0.7 m/s³다.
   - 명령 변화율이 큰 모델일수록 미지 가속 착륙률이 높았다(ρ=0.39, 기술 통계).
5. **그래프 경로는 쓰이지만 온톨로지 타입 배치는 거의 쓰이지 않는다(P6).**
   - 보정을 끄면 행동이 0.05 m/s²(기본 출력 RMS의 약 31%) 바뀐다.
   - 같은 파라미터에 짝 모델의 관계 타입을 넣으면 행동은 0.006–0.007 m/s²만 바뀌고, 폐루프 착륙률은 −1%p(TOSM), −3%p(Shuffled) 바뀐다.
   - 구조 효과(Shuffled−MLP)와 타입 효과(TOSM−Shuffled)의 시드 짝 구간은 모두 0을 포함한다.

결론적으로, 의미 관계 배치의 독립 이점이 보이지 않은 직접적인 이유는 다음 두 가지다. 첫째, 학습된 그래프 보정이 관계 타입에 거의 의존하지 않는다. 둘째, 성능을 좌우하는 공통 병목(가속 정보 부재와 낮은 응답 이득)이 관계 구조와 무관하다. 이 결론은 학습 시드 5개의 개발 모델에 대한 진단이며 인과 증명이 아니다.

- 행동 크기에 대한 벌점(control)은 사실상 0이므로, 과소 반응을 제어 비용 탓으로 볼 근거는 없다.
- 학습 분포의 가속은 0.3–0.8 m/s²였으므로, 큰 가속에 맞는 이득이 학습될 기회가 적었다는 해석은 가능하다. 그러나 이 진단만으로 확정하지 않는다.

## Q4. 행동 위상

- **변환 단계:** Gaussian latent μ(σ = exp(logStd) ≈ 0.11–0.13, 상태 무관) → tanh → 한계(a_x 2.5, a_z 2.0 m/s²) → 적용이다. direct policy라 감독기 수정은 모든 단계에서 0이고, 요청 명령과 적용 명령의 차이도 0이다.
- **포화:** |tanh μ| > 0.95인 결정은 네 방법·네 단계 모두 0%다.
- **행동 크기:** 가속 단계 평균 |μ_x|는 0.09다. v2 미지 가속에서는 0.16이고, 요청 가속으로 약 0.40 m/s²다.
- **명령 변화율 RMS(a_x):** 추종 0.57–0.63, 가속 0.68–0.76, 누락 0.40–0.48, 접촉 0.34–0.38 m/s³다. 방법 간 차이는 시드 구간 안이다.
- **인접 상태 간 정책 변화:** 잡음 반복 KL 0.044–0.068, UGV 속도 ±0.1 m/s KL 0.039–0.048 nats로 작다.
- **성능과의 연결(기술 통계):** 명령 변화율 대 미지 가속 착륙률 ρ = 0.39, aim ρ = −0.37이다.
- **판정:** 부드러운 행동(포화 없음, 작은 KL)은 확보됐지만 충분한 운동 대응과 양립하지 않았다. 행동 공간의 대부분을 쓰지 않는 낮은 이득 제어기다.

## P6. 온톨로지 의미 관계의 독립적 효과

ablation과 타입 교환은 **학습된 정책의 의존도**를 재는 것이다. 처음부터 그래프 없이, 또는 다른 타입으로 학습한 모델과의 비교가 아니다.

| 분리 대상 | 측정 | 결과 (학습 시드 5개) |
|---|---|---|
| R-GAT 경로 자체의 기능적 기여 | 보정 끔: 개방 루프 행동 변화 | TOSM 0.054, Shuffled 0.056, MLP 0.032 m/s² (기본 출력 RMS의 31%, 31%, 23%) |
| | 보정 끔: 폐루프 미지 가속 착륙률 변화 (기존 진단) | TOSM −16.4%p [−46.7, +13.9], Shuffled −20.0%p [−55.0, +15.0], MLP +0.2%p. 시드별 편차가 매우 크다. |
| 노드 분할·메시지 전달 구조 | Shuffled − Residual-MLP (v2 결과) | 미지 가속 +5.2%p [−12.5, +22.9], 전체 OOD +5.0%p [−11.7, +21.7] |
| 올바른 관계 타입 배치의 추가 효과 | TOSM − Shuffled (v2 결과) | 미지 가속 −5.8%p [−30.1, +18.5], 전체 OOD −2.2%p [−15.8, +11.4] |
| 학습된 그래프의 타입 의존도 | 같은 파라미터에 짝 모델 타입 적용 | 개방 루프 행동 변화 0.006–0.007 m/s² (보정 효과의 약 1/8). 폐루프 미지 가속 착륙률 TOSM −1.0%p [−6.2, +4.2], Shuffled −3.0%p [−13.4, +7.4] |

- 구조 효과의 대조(Shuffled − MLP)는 보정 분기의 형식(그래프 vs MLP)과 용량 배치가 함께 달라서 순수한 "구조" 효과가 아니다.
- **판정:** 그래프 경로는 일부 모델에서 기능적으로 중요하다. 그러나 학습된 관계별 가중치는 타입을 바꿔 끼워도 행동이 거의 같을 만큼 서로 대체 가능하다. 따라서 의미 타입 배치가 독립적으로 줄 수 있는 차이가 작다.

## 네 가정 판정

| 가정 | 확인한 것 | 이번 자료에서의 판정 |
|---|---|---|
| 상태 연속성 (비슷한 상태 → 비슷한 행동) | 민감도·잡음 KL 작음, 방법 간 같음 | 충족된다. 병목이 아니고 TOSM 고유 효과도 없다. |
| 행동의 상태 의존성 | 응답 방향 정확, 이득 0.16–0.22× 기준, 분기에서 더 강한 반응이 유리 | 방향은 충족, 크기는 부족. 모든 방법의 공통 병목이다. |
| 보상 밀도 | shaping·readiness가 매 결정 신호를 줌, control ≈ 0 | 희소성 문제는 아니다. 학습 가속 범위가 좁다는 점은 별도 요인 후보다. |
| 행동 공간 구조 | 포화 0, 감독 수정 0, 작은 행동 크기 | 행동 공간 제약은 아니다. 낮은 이득이 문제다. |
| 관계 구조 | 경로 사용, 타입 의존 매우 작음 | 의미 타입의 독립 기여는 측정 가능한 크기가 아니다. |

## 기존 평가와의 차이와 한계

- 개방 루프 상태는 정책과 무관한 기준 구동기의 궤적이다. 각 정책이 실제로 방문하는 상태 분포와 다르다.
  - 기준 구동기가 빨리 착륙해서 UGV 가속 중인 기준 상태는 489개 중 34개, stale 10개, 시야 경계 12개뿐이고 시야 밖 상태는 없다.
  - 가속 대응은 폐루프 분기와 단계 분해로 보완했다.
- 성능 연결(Spearman)은 방법과 시드가 섞인 20개 모델의 기술 통계다. 검정이나 인과 해석이 아니다.
- 분기는 a_x ±0.25를 0.5 s 동안 준 국소 시험이다. 더 큰 변화나 다른 축은 보지 않았다.
- 폐루프는 v2 개발 환경 9001–9020(이미 공개된 표본)만 썼다. 확인 환경은 그대로 닫혀 있다.
- 모든 구간은 학습 시드 5개의 95% t 구간이다(기술 통계, 판정 기준 아님).
- 그림 색은 색각 이상 검증을 통과한 범주색(파랑·초록·마젠타·노랑)과 표식 모양을 함께 썼다. 기존 registry의 PPO·TOSM 색은 이 검증에서 서로 구분되지 않는다(ΔE 2.7).

## 정정: 프로토콜 v2 누락 상한 근거

P0 감사 중 [프로토콜 v2](GENERALIZATION_PROTOCOL_V2_KO.md)의 누락 사다리 상한 근거("3.0 s 이상이면 감독기 개입")가 direct policy 계약에서 사실이 아님을 확인하고, 해당 문서에 정정 절을 추가했다. 등록된 v2 결과는 바꾸지 않았다.

## 새 학습을 검토한다면 (미실행, 사용자 결정 필요)

- **근거:** 네 방법 모두 미지 가속에서 같은 과소 반응을 보인다. o_t에는 UGV 가속 정보가 없고 정책은 기억이 없다. 학습된 그래프는 관계 타입에 거의 의존하지 않는다.
