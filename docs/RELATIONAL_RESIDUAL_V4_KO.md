# 기본 출력 초기화를 분리하는 관계 잔차 v4 (2026-10-26)

현재 개발 후보는 `relational-residual-v4.0`, 프로필/인코더 `relational_residual_v4`, 패키지 `landing2d.residual_base_init`다. [v3 전체 결과](RELATIONAL_RESIDUAL_V3_KO.md)는 세 개발 기준 모두 실패했다. v4는 초기화 한 요인의 영향을 분리하는 후보이며 성능 우위를 입증한 버전이 아니다.

**2026-10-26 짝 개발 완료·미채택:** 모든 방법이 5개 시드에서 학습 기준을 통과했지만, OOD 평균 방향과 조건별 강인성 기준을 통과하지 못했다. 새 개발 401–405와 확인 411–420은 실행하지 않았다. 아래 사전 계획·수식은 완료된 실험의 재현 계약으로 보존하고, 마지막 절에 전체 결과를 기록한다.

## 바꾸는 항목 하나

기본 MLP의 마지막 출력 가중치만 v3 이전의 fan-in Gaussian 초기화로 복원한다.

\[
\mu(o)=B_2\tanh(B_1o+b_1)+b_2+\sigma(\beta)\tanh(R e(T(o))+b_r),
\qquad (B_2)_{ij}\sim\mathcal N(0,0.1^2/n_{\mathrm{hidden}}),\quad R=0.
\]

일반 PPO의 마지막 출력 W에도 같은 기존 gain 0.1을 적용한다. 잔차 MLP와 두 그래프의 보정 출력 R=0, 기존 0 bias, beta=−2, 은닉 특징, 난수 소비 순서, Critic, logσ=−2는 유지한다. 따라서 세 잔차 방법의 초기 행동 평균은 같은 raw base이고, 첫 PPO minibatch부터 기본 은닉층에 기울기가 전달된다. 보정 내부의 기울기는 R이 갱신된 다음 활성화된다. Plain PPO는 폭이 달라 초기 함수가 잔차 방법들과 정확히 같다는 주장은 하지 않는다. TOSM과 Shuffled는 초기 함수·가중치가 같고 관계별 기울기가 모이는 배치가 다르다.

0.1은 이번 실패 시드에 맞춰 탐색한 값이 아니라 기존 초기화의 복원이다. v3의 0 초기화가 실패 원인이었다는 증거는 아직 없다. 같은 시드의 전체 짝 비교로 판단한다. v3의 미지 가속 접지 위치·상대속도 실패도 이 변경으로 해결된다고 가정하지 않는다.

## 유지하는 계약

- v3의 2D 물리·센서·10차원 원 관측·reward_v5·행동·종료·학습 분포·PPO 손실·학습률·탐색·예산·validation 선택/조기 종료·평가 조건을 유지한다.
- `tosm4_motion_v1`, 네 노드·7간선, `masked_own_vx_v1`, 노드별 사영·H0 증거·두 홉·모든 노드 readout과 공통 raw Critic을 유지한다. 순전파·역전파는 보관 v3 함수를 공유한다.
- 파라미터 수 PPO 2,095 / Residual-MLP 2,098 / TOSM·Shuffled 2,089. 보정 외 새 입력·보조 손실·제어기·필터 없음.
- 새 알고리즘 버전으로 네 방법 모두 새로 학습한다. 기존 PPO의 학습 서명과 호환 등록하지 않는다. 보관 모델은 이전 설정·서명 그대로 유지한다.

## 본 학습 전 고정 계획

1. 구현·PPO 기울기·수치 미분·네 방법 1 update·저장/재생 및 보관 모델 회귀를 실제 MATLAB에서 검증하고 소스 SHA-256을 등록한다.
2. **짝 개발 381–385×네 방법**을 같은 750×6 상한과 validation 규칙으로 모두 새로 학습한다. 출력은 `results/relational_residual_v4/`, 단계 이름은 `paired-development`다. v3 모델을 덮어쓰지 않는다.
3. 같은 여섯 ID/OOD 셀·환경 9001–9100 각 100개, 총 12,000개를 평가한다. 모든 방법 Reached80·선택 검증 80% 이상 5/5와 기존 validation 중앙값 조건, 세 OOD 차이 양수, motion/noise 성공·위험 접촉·aim RMS 방향 기준을 그대로 적용한다. v3와의 짝 변화도 모두 보고한다. 실패 시드 제외·재시작·예산 연장·기준 완화 금지.
4. 짝 개발의 세 주 비교는 기존 개별 98.3333% t 구간을 보고한다. 이는 개발/원인 분리 자료이며 목표 완료 근거가 아니다. 통과한 경우에만 별도 등록한 **새 개발 401–405**를 진행한다. 현재 실행 진입점은 이 새 개발이나 확인을 자동으로 열지 않는다.
5. 새 개발도 같은 전체 기준을 통과해야 미사용 확인 **411–420**, 환경 9101–9200을 별도 등록할 수 있다. 이전 391–400은 미사용으로 보존한다. 첫 확인 family alpha=.025와 세 개별 99.1667% 구간, 이후 alpha spending 및 전체 목표 완료 조건은 그대로다.

## 구현 검사와 실행

로컬 복사본에서 초기화 복원의 가능성을 확인한 뒤 정식 v4를 구현했다. 실제 MATLAB에서 20개 초기 Actor의 변경 범위·공통 Critic·탐색 분산·세 잔차 초기 함수 일치·PPO 기울기를 확인했다. 공유 인코더 미분 최대 오차는 5.3e−11 미만이다.

공개 `run_check`의 네 방법 1 update·24개 smoke 평가와 전체 통합 검사도 종료 코드 0으로 완료했다. 보관 잔차 v1/v2/v3의 총 60개 모델 출력·초기값 및 45개 인코더 미분, minimal v3.1/v3.2 모델이 비트 단위로 재현됐다. 기존 13개 minimal·14개 공통·13개 trace 검사, 보관 v2 PPO의 1 update, 네 모델 저장/복원, 8개 라이브 궤적 재생과 S2 네 에피소드를 확인했다. 두 smoke 그림은 TEST ONLY 표시를 확인했다. 실행/검산/실패 재현 스크립트의 실제 MATLAB 정적 검사도 통과했다. 전부 **구현 검사이며 성능 근거가 아니다**.

근거는 `results/goal_generalization_20261025/residual_v4_candidate_check.mat`, `residual_v4_public_check.mat`, `residual_v4_integration_checks.mat`, `residual_v4_launch_checks.mat`와 각 로그다. 보존 CSV 456개의 시드 필드와 체크포인트 이름 검사에서 새 개발/확인 예약 및 확인 환경과 겹친 기록은 없었다(삭제·미기록 이력까지 인증하는 검사는 아니다). 최종 코드·문서·검사·실행/분석 스크립트와 v3 비교 원자료의 SHA-256을 등록한 뒤 짝 개발을 실행한다.

```matlab

run_check('residual-v3')         % 보관 v3 검사
run                             % v4 짝 개발, 네 방법 모두 새 학습/일치 모델 로드
run_live('S3',struct('trainSeeds',381,'replicates',10))
```

변경 전 252개 코드·문서는 `results/archive/pre_residual_v4_20261026/`에 보존했다. v3의 원자료·등록 스냅샷·실패 재현은 원래 폴더에 남는다. 이 후보의 구현 검사가 통과해도 성능은 아직 검증되지 않은 상태다.

TOSM의 미지 가속 500개 중 447개가 성공했다. 사전 고정 실패 분류는 접지 위치 초과 13개, 수평 상대속도 초과 5개, 재획득 실패 1개, 시야 이탈 27개, 공중 정지 시간초과 7개다. 시야 이탈 분류는 TOSM 5.4%, PPO 1.4%, Residual-MLP 1.6%, Shuffled 0.4%다. 이는 실패 양상의 기술이며, 그래프의 특정 간선이 원인이라는 증거는 아니다. 접촉 위험이 낮아졌더라도 착륙률·추종 오차·시야 유지가 함께 좋아진 것은 아니다.

긴 누락에서 TOSM의 평균 착륙률과 위험 접촉은 유리한 방향이지만, 미지 가속 및 잡음의 기존 전체 강인성 기준은 충족하지 못했다. 조건 하나의 수치만 골라 목표 달성으로 해석하지 않는다.

### v3와 같은 시드의 초기화 비교

PPO는 Reached80/선택 검증 80% 이상이 3/5→5/5, Shuffled는 4/5→5/5가 됐다. TOSM과 Residual-MLP는 두 버전 모두 5/5다. v4−v3의 평균 AUC 변화는 PPO +0.303733, Residual-MLP +0.070567, TOSM −0.002233, Shuffled +0.134200이다. OOD 착륙률 변화는 각각 +36.33, −2.47, −0.67, +20.33%p다.

따라서 이번 다섯 짝에서는 기본 출력 초기화 복원 후 이전의 세 학습 실패가 회복됐지만, TOSM 일반화 우위가 생기지는 않았다. 이 결과를 모든 시드의 보편적인 초기화 효과나 운동 좌표 변경의 효과로 확대하지 않는다. 모든 20개 짝 변화는 `paired_v3_v4_by_seed.csv`에 보존했다.
