# v3.1 개발 결과 — PPO 대비 성능 개선 미입증

2026-10-24. 승인된 **개발 5시드 × 3방법의 본 학습 15개와 고정 ID/OOD 평가 9,000개를 완료**했다. 이번 v3.1을 일반화·강인성 개선안으로 판정할 근거는 부족하다. OOD 착륙률의 점추정은 PPO보다 낮고, 두 주 비교의 신뢰구간은 모두 0을 포함한다.

관측 품질이 두 번째 홉의 운동 정보 선택에 영향을 주는 경로는 학습된 모델에서도 확인했다. 그러나 이 기능이 안정적인 착륙 학습과 성능 향상으로 이어지지는 않았다.

## 1. 실행 범위와 비교 조건

- 학습 시드 271–275, PPO / TOSM-RGAT PPO / Shuffled-RGAT PPO. 모든 시드를 포함했다.
- 방법별 1,419개 파라미터, 같은 10차원 관측·2D 물리·센서·reward_v5·행동·종료·PPO 손실·탐색·예산·검증 규칙.
- 750 update × 6 episodes 상한. 검증으로만 체크포인트를 선택하고 공통 plateau 규칙을 적용했다.
- 평가 시드 9001–9100. 가속·누락·잡음 각각 ID/OOD 100개씩, 모델당 600개다. 주 지표는 세 OOD 요인의 동등 가중 착륙률이다.
- 분석 단위는 **학습 시드 5개**다. 9,000개 에피소드를 독립적인 방법 반복으로 취급하지 않는다.
- 확인 시드 281–290과 확인 평가 시드 9101–9200은 사용하지 않았다.

설계와 수식은 [v3.1 설계](MINIMAL_V31_DESIGN_KO.md), 고정 조건·통계는 [실험 설계](EXPERIMENT_DESIGN_KO.md)에 있다.

## 2. 주 결과

각 값은 학습 시드별 지표를 먼저 계산한 뒤 5개 시드에 걸쳐 평균낸 값이다. ID는 세 요인에 대응하는 조건부 참조 평균이다.

| 방법 | ID 착륙률 | OOD 착륙률 | OOD 위험 접촉 | OOD aim error RMS |
|---|---:|---:|---:|---:|
| PPO | 79.80% | **77.93%** | 2.47% | 1.275 m |
| TOSM | 60.60% | **59.07%** | 3.27% | 6.555 m |
| Shuffled | 44.80% | **44.87%** | 3.00% | 2.161 m |

| 사전 고정 주 비교 | OOD 착륙률 짝 차이 | 개별 97.5% t 구간 |
|---|---:|---:|
| TOSM − Shuffled | +14.20%p | [−103.96, +132.36]%p |
| TOSM − PPO | **−18.87%p** | [−88.90, +51.16]%p |

두 비교에 Bonferroni 보정을 적용한 구간이다. 모두 0을 포함해 우월성을 뒷받침하지 않는다. 표본이 5개이고 시드별 차이가 매우 커 구간도 넓다. 저장된 t 구간을 절단하지 않아 첫 구간은 가능한 차이 범위 ±100%p를 넘는다. PPO의 통계적 우월성을 확정한 결과로도 해석하지 않는다.

| 학습 시드 | PPO | TOSM | Shuffled | TOSM − PPO |
|---|---:|---:|---:|---:|
| 271 | 0.67% | 2.00% | 99.33% | +1.33%p |

## 3. 환경 제약별 결과

| OOD 조건 | PPO 착륙률 | TOSM 착륙률 | Shuffled 착륙률 |
|---|---:|---:|---:|
| UGV 가속 1.0–1.5 m/s² | 76.00% | 58.80% | 44.00% |
| 관측 누락 1.2–2.0초 | 79.00% | 60.00% | 45.60% |
| 센서 잡음 표준편차 ×2 | 78.80% | 58.40% | 45.00% |

**급가속:** TOSM의 aim error RMS는 11.869 m, PPO는 1.911 m였다. 외부 누락을 제외한 접근 중 시야 이탈 시간은 각각 10.748초와 2.294초였다. 이 조건에서 TOSM의 추종 강인성이 좋아졌다고 볼 수 없다. 시험 대상은 연속적인 UGV 가속이며 착륙지 순간이동·임의 방향 반전은 포함하지 않는다.

**센서 잡음:** TOSM의 착륙률은 ID 60.60% → OOD 58.40%, 위험 접촉은 1.80% → 5.40%였다. PPO는 80.00% → 78.80%, 위험 접촉 1.00% → 1.40%였다. OOD 명령 변화 RMS도 TOSM 1.884 m/s³, PPO 1.462 m/s³였다. 착륙·안전·명령 변화를 함께 보면 잡음 강인성 향상 근거가 없다.

**관측 누락:** TOSM은 60.40% → 60.00%, PPO는 79.80% → 79.00%였다. TOSM의 감소폭이 더 작아도 절대 착륙률이 낮으므로 우위로 해석하지 않는다. 전체 세 요인 평균 감소도 TOSM 1.53%p, PPO 1.87%p지만 같은 주의가 필요하다.

사후 노출 점검에서 가속 OOD 에피소드는 **세 방법 모두 100%가 가속 구간을 경험**했다. 누락 OOD의 실제 누락 노출 비율은 PPO 99.6%, TOSM 100%, Shuffled 99.6%였다. 이 점검은 원래 시나리오 시드와 종료 시각으로 계산했고, 주 평가의 에피소드나 조건을 선택·제외하는 데 쓰지 않았다.

## 4. 확인된 병목과 아직 확정할 수 없는 기전

### 학습 안정성이 먼저 부족하다

| 방법 | validation 착륙률 80% 도달 | validation AUC [0,750] |
|---|---:|---:|
| PPO | 4/5 | 0.6525 |
| TOSM | 3/5 | 0.3959 |
| Shuffled | 2/5 | 0.3278 |

TOSM 시드 271·274는 750회 상한까지 충분한 착륙 정책을 학습하지 못했다. 선택된 체크포인트는 각각 update 25·250이고 선택 시 검증 착륙률은 모두 0%였다. Shuffled 시드 272·274도 학습에 실패했고, 시드 275는 선택 시 검증 착륙률 30%의 부분 학습에 그쳤다.

TOSM−PPO의 격차는 ID에서 −19.20%p, OOD에서 −18.87%p다. **성능 격차의 대부분이 분포 전환 전에 이미 존재한다.** 현재 결과에서 우선 해결할 문제는 안정적인 기본 착륙 학습이다.

선택된 TOSM 정책의 OOD 시간 초과율은 37.67%(PPO 19.60%)였다. 사전 고정 실패 분류의 `FOV_LOSS` 비율은 세 OOD 요인 평균 30.87%(PPO 9.00%)였다. 단순히 움직임이 작거나 명령이 부드러운 정책을 강인한 정책으로 취급할 수 없다.

학습 곡선: [5시드 평균 validation 곡선](../results/minimal_v31/generalization_v1/development/s271-272-273-274-275/figures/learning.png). 조기 종료 이후 값은 등록한 AUC 규칙에 따라 유지한다. 동시 실행 수가 달라진 실행이므로 모델별 벽시계 시간을 공정한 속도 비교로 쓰지 않는다.

### 기울기 단절과 품질 경로 부재는 확인되지 않았다

구현 전 검사에서 인코더 전체 파라미터·입력 유한차분과 실제 PPO 손실 미분을 검증했다. 실제 학습 기록에서도 실패한 TOSM 271·274의 마지막 검증 구간 Actor 인코더 기울기 노름은 각각 **2.544, 1.898**이었다. 이는 클리핑 전 기록값이며 기울기 단절의 증거가 아니다. 15개 모델의 저장된 Actor/Critic 파라미터와 검증 return은 모두 유한했다.

추가로, 기존 진단과 같은 validation 2001–2004의 정책 독립 관측 44개를 사용했다. 품질 두 성분만 fresh=[1,0], stale=[0,0.6]으로 바꾸는 **입력 경로 진단**이며 실제 센서 잡음 실험이나 관계의 인과적 중요도 평가가 아니다.

- 학습된 그래프 모델 10개 모두 첫 홉의 두 운동 간선 log-odds 변화는 0이었다.
- 두 번째 홉의 최대 절대 변화는 모델별 **0.007769–0.10249**로, 10개 모두 0이 아니었다.
- 초기값 대비 선택된 Actor 인코더 파라미터 변화 노름은 **0.18291–1.1436**이었다. 선택 update가 다르므로 이 크기로 방법의 우열을 비교하지 않는다.

따라서 v3.1의 품질 조건부 선택 경로는 실제 모델에도 존재한다. 이 진단값은 별도의 ‘귀납적 편향 점수’나 성능 근거가 아니다.

### 아직 분리하지 못한 원인

공유 두 홉, 반복 tanh, 8차원 종착 표현이 최적화 난도를 높였을 가능성은 있지만 이번 실험으로 각각의 인과 효과를 식별하지 않았다. v3→v3.1에서는 홉 수와 attention 수식이 함께 바뀌었고 학습 시드도 달라, 과거 v3 결과와 단순 비교해 특정 변경이 실패를 일으켰다고 단정할 수 없다.

품질 입력에는 관측 갱신 여부·나이가 들어가며 실제 오차나 잡음 분산의 정답은 없다. 신선한 관측의 잡음 증가를 품질 노드가 항상 식별할 수 있는 구조도 아니다. 경로를 열었다는 사실과 잡음에 유리한 처리 방법을 PPO가 안정적으로 학습했다는 사실을 구분해야 한다.

현재 병목은 **허용된 관계 경로를 통한 갱신 자체가 아니라, 그 갱신이 여러 시드에서 안정적인 추종·착륙 정책을 만들도록 하는 것**이다. 다음 구조 변경을 검토한다면 validation에서 학습 안정성의 원인을 한 번에 하나씩 분리하는 작업이 먼저 필요하다. 이번 결과를 일반화 향상을 입증한 확인 실험으로 사용하지 않는다.

## 5. 검증과 실행 기록

- MATLAB R2025b에서 본 학습 15개, 고정 평가 9,000개 완료.
- 15개 체크포인트의 학습 서명과 평가 전 manifest SHA-256 일치 확인.
- 등록한 `src` 파일 **185개 전부 변경 없음** 확인.
- 9,000행의 성공·위험 접촉·aim error·명령 변화·비행 시간과 저장된 모델 파라미터가 모두 유한함을 확인.
- 공통 PnP 계산 `estimatePadPose`의 선형해 경로에서 랭크 부족 경고가 기록됐다. 학습 중 경고는 4회였다. 경고를 숨기거나 해당 에피소드를 제외하지 않았고, 관측·환경 코드를 변경하지 않았다.
- 구조·학습 경로 11/11, 기존 공통 코드 14/14, 보관 trace A01–A13 및 세 방법 1 update smoke는 본 학습 전에 통과했다. 해당 시험은 성능 증거가 아니다.

실행 조정은 `results/minimal_v31/development/execution_note.md`에 기록했다. 초기에 미완료 학습을 2→8개 스레드로 재시작했고, 15개 모델 저장 후 평가용 프로세스 워커 6개가 가용 가상 메모리를 약 1.94 GiB까지 줄여 해당 배치와 소속 워커만 종료했다. 사용자 데스크톱 MATLAB은 유지했다. 이후 **모델·등록 조건·manifest를 확인하고 한 프로세스의 공유 스레드 4개로 9,000개 전체를 다시 평가**했다. 미완료 평가 결과를 합치지 않았다. 수치 설정이나 선택 규칙은 바꾸지 않았다.
