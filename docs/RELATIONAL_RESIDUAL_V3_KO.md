# 운동 개체의 의미를 맞춘 관계 잔차 v3 (2026-10-26)

`relational-residual-v3.0`의 개발 실험을 완료했으며 **개발 기준 실패로 미채택**이다. 인코더·프로필은 `relational_residual_v3`, 패키지는 `landing2d.residual_motion`이다. 원 관측을 보존하는 기본 MLP, 작은 관계 보정 분기, 공통 벡터 Critic의 큰 틀을 유지한 후보이며 성능 우위를 입증하지 못했다. 확인 시드 391–400은 사용하지 않았다.

## 변경 근거와 해석 범위

[v2 전체 개발](RELATIONAL_RESIDUAL_V2_KO.md)은 20개 모델·12,000개 평가를 검산했지만 개발 기준 세 가지 모두 실패했다. TOSM OOD 착륙률 96.40%는 PPO 97.93%보다 낮았고, 가속 조건의 시야 이탈·공중 정지 실패가 남았다. Residual-MLP 한 시드는 검증 착륙률이 750 update 내내 0%였다. v2 확인 371–380은 열지 않는다.

첨부안에서 아직 반영하지 않았던 물리 개체별 운동 특징을 반영한다. 기존 `OwnMotion`에는 수직속도·자세만 있었고 수평속도는 없었다. 이미 제공되는 상대속도와 플랫폼 속도에서 드론 수평속도를 복원하면 노드 이름과 실제 특징이 일치한다. 별도로 네 방법의 초기 행동 분포를 통일해 임의 초기 출력 차이를 제거한다. 후자는 학습 안정성 개선 가설이며 v2 실패의 유일 원인이 초기화였다는 증거는 없다. 두 변경을 함께 적용하므로 최종 차이를 어느 하나만의 인과 효과로 주장하지 않는다.

## 입력과 물리 좌표

센서의 10차원 원 관측 `o`와 기본 MLP·Critic·일반 PPO 입력은 그대로다. 보정 분기만 `u=T(o)`를 사용한다. Residual-MLP와 두 그래프 방법에 **동일한 T**를 적용한다.

원 관측의 3·4번 성분을 각각 r, t라 쓰면 같은 공개 속도 척도 s에 대해

\[
r=\frac{v_T-v_U}{s+|v_T-v_U|},\qquad t=\frac{v_T}{s+|v_T|}.
\]

A=1−|r|, B=1−|t|, N=tA−rB라 할 때

\[
\boxed{u_3=\frac{N}{AB+|N|}=\frac{v_U}{s+|v_U|}},\qquad u_k=o_k\;(k\ne3).
\]

이는 정규화 값의 단순 뺄셈이 아니다. 큰 물리 속도를 각각 역정규화하지 않는 안정적인 유리식이다. 추정기 초기화 전에는 o1–4의 기존 0 마스크가 유지되므로 u3도 **가용하지 않은 속도의 0 자리표시자**다. 이때 실제 항법 속도가 추가되는 것이 아니다. 비전이 끊긴 뒤에도 기존 추정기가 제공하는 값만 사용한다.

유한 물리 속도에 대응하는 열린 구간에서는 역변환이 가능하다. 부동소수점 값 두 개가 정확히 ±1에 도달해 분모가 0이면 잃어버린 크기를 복원할 수 없으므로 u3과 해당 미분을 0으로 처리한다. 닫힌 전체 구간에서 일대일 변환이라고 주장하지 않는다. 원 관측은 기본 경로에 보존된다.

| 노드 | 보정 좌표 | 의미 |
|---|---|---|
| ObservationQuality | u9–10 | 갱신·관측 나이 |
| TargetMotion | u4 | 추정 플랫폼 수평속도 |
| OwnMotion | u3, u5–8 | 복원 드론 수평속도·수직속도·자세 |
| RelativeState | u1–2 | 상대 위치·높이 |

`tosm4_motion_v1`은 네 노드와 기존 7간선을 유지한다. Quality→Relative는 `qualifiesEstimate`, Target/Own→Relative는 `informsMotion`, 나머지는 네 self 간선이다. 품질 입력은 실제 확률적 신뢰도나 NIS로 해석하지 않는다.

## 정책과 공통 초기화

\[
\mu(o)=B_2\tanh(B_1o+b_1)+b_2+
\operatorname{sigmoid}(\beta)\tanh(R e(T(o))+b_r),\quad\beta_0=-2.
\]

기본 MLP는 10→74→2, 그래프 보정은 노드별 폭 8 사영·H0 증거를 유지하는 두 홉 공유 attention·네 노드 전체 readout 32→2다. Residual-MLP 보정은 10→36→2다. 이 연산과 공통 PPO 손실은 v2와 같다.

네 Actor 모두 최종 평균 출력 가중치를 0으로 시작한다. 일반 PPO는 마지막 W, 잔차 방법은 B2와 R이 0이다. 기존 0 bias·무작위 은닉 특징·logσ=−2·Critic 초기값·난수 소비 순서는 유지한다. 따라서 초기 평균은 모두 정확히 0이고 같은 난수에서 행동 표본과 로그확률도 같다. 첫 minibatch에서는 출력층이 먼저 갱신되고, 다음 minibatch부터 내부 특징·관계 행렬로도 기울기가 전달된다. 학습 중 경로를 차단하거나 단계를 나누는 별도 규칙은 없다.

PPO의 초기화도 바뀌므로 네 방법 모두 새로 학습한다. 새 알고리즘 버전은 이전 PPO 경로와 호환된다고 등록하지 않는다. Actor 전체에 동일한 기울기 clip·학습률 2e−4, Critic에 5e−4를 적용한다. Critic은 모든 방법이 원 관측 10→55→1이며 파라미터 수는 PPO 2,095, Residual-MLP 2,098, TOSM·Shuffled 각각 2,089로 v2와 같다.

Shuffled는 위상·self·관계 수와 동일 특징을 보존하고 의미 간선 2/3개를 교란한다. TOSM과 Shuffled의 초기 함수·모든 초기 가중치는 같고, 관계 행렬에 기울기가 모이는 묶음이 다르다. 이 짝 비교가 관계 공유 배치의 기여를 검증한다. 일반 PPO와의 비교만으로 관계 의미의 효과를 단독 귀속하지 않는다.

## 학습 실패 재현과 다음 원인 분리

세 모델은 750 update 동안 검증 착륙률이 계속 0%였다. 선택된 원래 검증 20개씩, 총 60개를 모두 재현했으며 기록된 결과 비율과 평균 return이 일치했다.

PPO 두 모델은 초기에 상승한 뒤 높은 고도에 머물렀고, Shuffled는 낮은 고도까지 내려온 뒤 착륙하지 못했다. 이들을 같은 실패 궤적으로 취급하지 않는다. 20개 모델을 동일한 10개 기준 궤적의 입력에서 비교한 별도 진단에서는 관측 갱신 쌍에 대한 수직 가속도 반응이 PPO 실패 모델에서 각각 +0.902/+0.510m/s², Shuffled 실패 모델에서는 −1.260m/s²였다. 이는 입력의 계산상 영향이며 학습 실패 원인이나 물리적으로 실현된 센서 개입 효과를 입증하지 않는다. 전체 모델 자료는 `results/goal_generalization_20261025/residual_v3_all_quality_reference/`에 있다.

다음 단계에서는 기본 출력 초기화를 먼저 분리해 검증한다. v3의 0 출력 대신 이전 fan-in Gaussian gain 0.1을 기본 MLP 출력에만 복원하고, 잔차 출력 R=0은 유지하는 시험용 복사본을 실제 MATLAB에서 검사했다. 20개 초기 Actor에서 다른 수치 파라미터·Critic·탐색 분산이 보존됐고, 세 잔차 방법의 초기 함수가 같으며 기본 은닉층과 이후 관계 분기에 기울기가 전달됐다. `TEST_ONLY_base_output_restoration_prospective*`는 구현 가능성 자료다. 초기화가 이번 실패의 원인이라는 결론이나 성능 개선 근거는 아니다. 이를 채택하더라도 모든 비교군·시드를 포함한 짝 학습과 별도의 새 개발 검증을 거쳐야 한다.

가속 조건의 위치·상대속도 실패는 별도로 남는다. 초기화 변경으로 해결된다고 가정하지 않는다. 향후 수정 후 보관 v3를 검증할 수 있도록 20개 모델 출력·초기값과 15개 인코더 미분을 44개 고정 입력에 저장했다(`residual_v3_fixture.mat`, TEST ONLY).
