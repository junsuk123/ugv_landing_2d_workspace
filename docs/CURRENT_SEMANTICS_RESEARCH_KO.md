# 현재 관측의 운동·접촉 관계를 이용한 착륙 연구 재구성

- 설계 버전: `current_semantics_v1`
- 작성일: 2026-10-27
- 상태: 새 알고리즘·비교 실험의 설계 및 구현 계약. 이 버전의 본 학습·성능 평가 결과는 아직 없다.
- 알고리즘 정의: [CURRENT_SEMANTICS_ALGORITHM_KO.md](CURRENT_SEMANTICS_ALGORITHM_KO.md)
- 실험 실행·판정 계약: [CURRENT_SEMANTICS_EXPERIMENT_KO.md](CURRENT_SEMANTICS_EXPERIMENT_KO.md)

## 1. 연구 목적

현재 관측에서 얻는 상대 운동, 수직 운동, 자세 및 관측 갱신 상태를 접근 진행과 접촉 조건에 연결하고, 이들 상황의 의존 관계를 정책 상태 표현에 반영한다. 연구 질문은 **동일한 현재 정보를 사용하는 비관계형 모델과 비교할 때, 이 관계 구조가 이동 플랫폼 착륙의 학습과 일반화에 유효한가**이다.

정책은 매 결정 시각의 공통 10차원 관측만 입력받는다. 관측 이력, 과거 행동, 시간 간선, 누적 임무 단계, 새로운 추정기 및 추가 감독 목표를 도입하지 않는다. 기존 2차원 물리·센서·PPO 보상·연속 2축 행동 계약을 유지한다.

현재 속도가 포함된 관측으로 접근·이탈 및 상승·하강의 현재 상태를 표현할 수 있다. 상대 가속도가 없으므로 속도 정합의 개선 추세를 단정하지 않으며, 현재 상태가 일정 시간 유지되었다고 해석하지 않는다.

## 2. 기존 원고 및 후속 후보와의 차이

| 항목 | 기존 7노드 원고 | 후속 잔차 후보 계열 | `current_semantics_v1` |
|---|---|---|---|
| 비교 목적 | 기존 PPO 대비 관계 표현 및 관계 배치 효과 | 원 관측 정책을 보존하면서 관계 보정의 일반화 효과 확인 | 파생 특징의 효과와 현재 운동–접촉 관계 구조의 효과를 분리 |

노드 수가 같아도 원고의 기존 7노드 모델과 새 모델은 동일한 알고리즘이 아니다. 새 구조에 기존 원고의 성공률·추종 오차 감소율을 적용하지 않는다. 과거 후보의 실패와 결과는 보존하며, 새 설계가 그 실패를 해결했다고 미리 규정하지 않는다.

## 3. 의미를 정의하는 위치와 학습되는 부분

### 3.1 사람이 정의하는 의미

물리 대상과 좌표계를 먼저 정의하고, 현재 상태가 임무에서 갖는 역할을 명시한다.

- 상대 위치·속도: 패드에 대한 수평 정렬 상태와 현재 변화 방향.
- 수직 운동: 패드까지의 높이와 현재 상승·하강 상태.
- 자세·각속도: 현재 접촉 자세 조건과 관련된 정보.
- 관측 갱신 상태: 상대 상태를 판단하는 관측의 갱신 여부와 경과시간.
- 접근 상황: 기존 접근선에 대한 오차와 현재 오차 변화 방향.
- 접촉 조건: 기존 착륙 판정의 위치·속도·자세 허용치에 대한 현재 값.
- 착륙 상황: 접근 상황과 접촉 조건을 결합하는 최종 정책 표현의 위치.

운동학적 특징과 허용치 대비 특징은 현재 관측의 결정론적 변환이다. 추가 센서 정보나 새로운 상태 추정치를 생성하지 않는다. 의미 정의 자체를 신경망이 발견했다고 표현하지 않는다.

### 3.2 R-GAT가 학습하는 부분

노드별 특징을 결합하는 사영, 관계별 변환, 어텐션 계산 및 Actor의 정책 파라미터를 PPO 목적에 따라 학습한다. 온톨로지가 지정한 입력 분할과 정보 전달 경로 안에서 착륙 제어에 유용한 상태 표현을 형성하는 것이 학습 내용이다.

어텐션은 정규화된 메시지 집계 비중이다. 보정된 관측 신뢰도, 안전 확률, 물리 인과적 중요도 또는 직접 지도된 관계 중요도로 해석하지 않는다. `ContactCondition`과 `LandingContext`의 임베딩도 별도 위험 확률이나 착륙 승인 신호가 아니다.

### 3.3 시간에 관한 주장 범위

그래프의 `현재 운동→접근·접촉 상황→착륙 상황` 경로는 현재 정보의 결합 순서이다. 실제 행동의 시간 순서나 임무 단계의 이력을 저장하지 않는다.

PPO는 rollout의 장기 수익과 이점 추정을 이용해 현재 행동의 이후 성과를 학습한다. 그러나 운용 시 Actor는 현재 관측에 조건화된다. 서로 다른 과거가 같은 현재 관측을 만들면 동일한 행동 분포를 출력한다. 기존 KF의 내부 추정 상태와 PPO 학습용 rollout은 유지되며, 정책 인코더에 별도 기억 장치를 추가하지 않는다.

## 4. 기존 `LandingCondition`의 재명명에 그치지 않기 위한 변경

이번 설계의 확인 가능한 차이는 다음 세 가지다.

1. **접근선과 패드 정렬의 현재 진행을 구분한다.** 기존 목표 `e_x*=m h_+`에 맞춰 `e_a=e_x-m h_+`와 접촉 전 `dot(e_a)=v_rel-m v_z`를 구성한다. 하강이 목표 접근 위치를 바꾸는 결합을 입력 특징으로 명시한다.
2. **상황을 결합하는 경로를 고정한다.** 운동·관측 노드가 접근·접촉 노드로 정보를 전달하고, 그 결과가 `LandingContext`로 모이는 두 홉의 경로를 사용한다.
3. **정보와 구조의 효과를 따로 검증한다.** 같은 파생 정보를 받는 Semantic-MLP와 같은 위상의 Untyped-GNN을 대조하여, 단순 특징 가공 및 그래프 구조를 관계 유형의 효과와 분리한다.

접촉 허용치 대비 특징 자체는 기존 원고에도 포함되어 있었다. 이를 신규 기여로 주장하지 않는다. 이번 차이는 위의 명시적 진행 특징, 상황 결합 경로 및 대조 설계의 묶음이며, 그 유용성은 새 실험으로 검증해야 한다.

기존 `computeReward`도 접근선 오차와 하강 중 상대 속도의 목표를 결합한다. 따라서 접근 진행식은 새로운 물리 법칙이나 보상 목표의 발견이 아니다. 기존 과제와 일치하는 현재 정보를 정책 입력의 관계 구조에 반영하는 변경이다.

## 5. 반증 가능한 가설과 결과 해석

| 가설 | 주 비교 | 지지에 필요한 관찰 | 지지되지 않을 때의 해석 |
|---|---|---|---|
| H1: 현재 파생 특징이 제어 학습에 유용하다 | Semantic-MLP − Raw-MLP | 등록한 성능 지표에서 재현되는 개선 | 해당 특징 가공의 실용적 이점 미확인 |
| H2: 관계 그래프의 정보 결합 구조가 유용하다 | Typed-RGAT 및 Untyped-GNN − Semantic-MLP | 같은 정보를 가진 MLP보다 안정적인 개선 | 그래프 표현의 추가 이점 미확인 |
| H3: 의미별 파라미터 공유가 추가로 유용하다 | Typed-RGAT − Untyped-GNN | 위상·입력·readout을 통제한 비교에서 개선 | 관계 유형의 독립적 기여 미확인 |

Typed-RGAT가 Raw-MLP보다 좋다는 결과만으로 H2·H3를 지지하지 않는다. Semantic-MLP와 비슷하고 둘 다 Raw-MLP보다 좋다면 특징 구성의 효과가 우선적인 설명이다. 두 그래프 모델이 비슷하고 Semantic-MLP보다 좋다면 그래프 구조의 효과를 검토할 수 있지만 관계 유형의 효과는 확정하지 않는다.

Typed-RGAT와 Untyped-GNN의 차이는 등록한 관계 분할에 따라 가중치를 나누어 공유하는 효과다. 현재 비교만으로 이 분할이 가능한 모든 다른 관계 분할보다 우수하거나, 관계 이름 자체의 의미를 신경망이 이해했다고 주장할 수 없다. 모든 관계 ID와 대응 파라미터를 일관되게 재명명하면 같은 함수를 나타낸다. 따라서 단순한 관계 이름 변경만으로 성능이 떨어져야 한다는 전제는 두지 않는다.

차이의 불확실성 구간이 0을 포함하면 우위가 확인되지 않은 것이다. 이를 자동으로 동등성이나 무효과의 증명으로 바꾸지 않는다. 성능 개선이 없을 때 실패 시드·조건을 제외하거나 후보별로 유리한 지표만 선택하지 않는다.

등록된 주 비교는 Typed-RGAT−Semantic-MLP와 Typed-RGAT−Untyped-GNN 두 개이며 각각 97.5% 시드 대응 구간을 사용한다. 위 표의 H1과 다른 추가 차이는 특징 효과를 이해하기 위한 보조·탐색 해석이다. 이를 등록된 두 주 비교와 같은 확인 주장으로 취급하지 않는다.

관계 구조에 관한 두 비교만 통과하고 기존 Raw-MLP보다 실제 착륙 성공률이 낮은 결과를 전체 연구 성공으로 처리하지 않는다. 개발에서는 Typed-RGAT−Raw-MLP의 OOD 성공률 평균 차이도 양수여야 한다. 확인에서는 두 주 비교를 통과한 뒤, 사전에 정한 후속 실용성 비교인 Typed-RGAT−Raw-MLP의 95% 시드 대응 구간 하한이 0보다 커야 한다. 기준 ID 성능·위험 접촉의 허용 기준도 함께 충족해야 하며, 구체적인 판정은 실험 계약을 따른다. 결과를 확인한 후 이 순서나 기준을 바꾸지 않는다.

## 6. 공정한 비교의 조건

### 6.1 정보 공정성

네 방법 모두 같은 현재 공통 10차원 관측을 사용한다. Semantic-MLP는 그래프의 변화하는 수치 특징을 담은 `flatPhi`를 입력받는다. 이 벡터에서 영 패딩과 상수 노드 ID를 제거해도, 입력 위치가 각 특징의 정체성을 나타내므로 그래프에 제공되는 현재 수치 정보는 보존된다.

Typed-RGAT와 Untyped-GNN은 같은 노드 특징, 간선 방향, 자기 연결, 공유 두 홉 및 `LandingContext` readout을 사용한다. Untyped-GNN은 네 의미 관계 유형을 하나로 합치고 자기 연결은 별도로 유지한다. 이는 간선을 없애 과거·현재 정보를 차단하는 대조가 아니다.

### 6.2 용량·학습 공정성

실제 사용되는 학습 파라미터 수와 구조를 기록한다. 폭의 차이로 규모를 근접하게 맞추더라도 함수군이 같아지는 것은 아니므로 정확한 수와 차이를 공개한다. 사용하지 않는 파라미터, 영 입력에만 연결된 가중치 또는 기능하지 않는 분기를 추가해 숫자를 맞추지 않는다.

환경 상호작용 수, PPO 설정, 검증 주기, 체크포인트 선택 규칙, 조기 종료 및 실패 처리 규칙은 방법 간 공통으로 유지한다. 공통 Critic의 값 손실이 Actor 전용 그래프 인코더를 직접 학습하는 것으로 서술하지 않는다.

### 6.3 판정의 단위

분석 단위는 독립 학습 시드다. 같은 평가 에피소드의 방법 차이는 학습 시드에 대응시켜 집계한다. 한 학습 정책의 수많은 평가 에피소드를 독립 학습 시드처럼 세지 않는다. 최종 평가는 개발 결과로 체크포인트나 지표를 다시 선택하는 데 사용하지 않는다.

구체적인 시드·예산·평가 셀·구간·판정 기준은 실험 계약에서 단일하게 관리한다. 이 문서에 별도의 실행 기준을 중복 등록하지 않는다.

## 7. 성능 외에 확인해야 할 구현 근거

- 물리 단위의 접근 오차 및 변화식이 정규화된 좌표의 잘못된 선형 결합으로 대체되지 않았는가.
- `flatPhi`가 그래프에 제공되는 모든 변화하는 특징을 보존하는가.
- 그래프의 모든 의미 관계가 두 홉 안에 `LandingContext`에 도달하는가.
- 공유 두 홉의 역전파에서 같은 파라미터에 두 사용 지점의 기울기가 합산되는가.
- 실제 PPO 정책 손실이 관계·어텐션 파라미터까지 전달되는가.
- Actor가 사용하는 원 관측 경로와 그래프 경로의 입력·차원을 정확히 기록했는가.
- 관측이 같을 때 별도 과거 호출에 의존하지 않는 결정론적 인코더인가.

이 항목은 구현과 학습 경로의 근거다. 통과 사실 자체를 착륙 성능 개선이나 의미 배치의 효용으로 해석하지 않는다.

## 8. 한계와 실패 가능성

1. **정보 한계:** 미지 가속, 장시간 관측 소실의 숨은 상태 및 과거 단계는 현재 관측만으로 완전히 구별되지 않을 수 있다.
2. **중복 특징:** 일부 의미 특징은 같은 상태를 다른 척도로 반복 표현한다. 개선이 있더라도 특징 가공과 정보 결합 구조의 효과를 구분해야 한다.
3. **관측 오차:** 접근·접촉 특징은 추정값에서 계산한다. 실제 운동·접촉 상태의 정답이 아니며, 갱신 시 추정 보정에 따른 차이가 나타날 수 있다.
4. **운동 의미의 범위:** 오차의 현재 변화 방향은 속도로 계산할 수 있지만, 속도 오차의 감소 추세나 안정적으로 유지된 시간은 알 수 없다.
5. **고정 구조의 부적합:** 설계한 관계가 과제에 불필요하거나 일반 MLP보다 표현을 제한할 수 있다. R-GAT 우위를 전제하지 않는다.
6. **정규화 경계:** 정확한 포화에서 잃은 물리 값을 복원할 수 없다. 수치적 유한성 처리와 물리 정보의 복구는 다른 문제다.
7. **안전 보장 부재:** 관측 품질·접촉 조건을 반영해도 안전 확률, 제어 불변 집합, 충돌 회피 보장 또는 규칙 준수를 제공하지 않는다.

## 9. 논문 구성 재작성안

### 연구 질문

현재 운동과 접촉 조건의 의존 관계를 명시한 상태 표현이, 같은 정보를 사용하는 비관계형 표현보다 이동 플랫폼 착륙에 유효한가?

### 방법

공통 10차원 현재 관측, 운동학적 진행 특징, 7노드·9개 의미 간선의 관계 정의, 공유 두 홉의 R-GAT, `LandingContext` readout 및 원 관측과 임베딩을 함께 사용하는 PPO Actor를 기술한다.

### 실험

Raw-MLP, Semantic-MLP, Untyped-GNN, Typed-RGAT의 정보·용량·학습 조건을 제시한다. 현재 버전의 독립 실행 산출물을 사용하고, 성공률뿐 아니라 위험 접촉·추종·최악 조건을 함께 해석한다.

### 결과 및 결론

본 실험이 완료되기 전에는 결과 수치를 작성하지 않는다. 결과가 확보되면 특징 가공, 그래프 구조, 관계 유형 중 어느 수준의 가설이 지지되는지 구별해 서술한다. 효과가 확인되지 않으면 그 범위와 조건을 연구 결과로 남긴다.

### 유지할 기여

- 기존 관측과 물리 목표에 부합하는 운동–접촉 관계를 명시적으로 구성한다.
- 추가 상태·시간 모델·보조 목표 없이 기존 R-GAT와 PPO로 해당 관계를 정책 입력에 반영한다.
- 같은 정보를 가진 비관계형·유형 없는 그래프 대조를 통해 기여 범위를 검증한다.

### 결과 없이 사용하지 않을 표현

- 관계 의미를 이해하거나 관계의 인과적 중요도를 학습했다.
- 행동 연쇄 또는 임무 단계의 순서를 학습했다.
- 온톨로지가 PPO의 일반화 한계를 해결했다.
- 접촉 조건 노드가 안전 착륙을 보장한다.
- 새 버전에서도 기존 원고의 성능 향상 수치가 성립한다.
