# UGV 착륙의 관계 기반 정책 표현 — 2D, MATLAB

현재 v3.1 연구 경로는 **4개 증거 노드 → 가중치를 공유하는 동적 R-GAT 2회 집계 → PPO**다. 첫 집계의 관측 품질 문맥이 두 번째 집계의 정보 선택에 도달하도록 모델을 수정했다. [변경 원인과 수식](docs/MINIMAL_V31_DESIGN_KO.md)에 근거를 정리했다. 동일한 10차원 관측·2D 물리·센서·보상·PPO 규칙과 방법별 1,419개 파라미터를 유지한다.

**개발 결과(2026-10-24):** 승인된 15개 모델 학습·9,000개 평가를 완료했다. OOD 착륙률은 PPO **77.93%**, TOSM **59.07%**, Shuffled **44.87%**였으며 두 주 비교의 구간 모두 0을 포함했다. 현재 v3.1을 성능 개선안으로 채택하지 않는다. 학습 정체·시야 이탈·잡음 조건과 재현 경로는 [전체 결과 분석](docs/MINIMAL_V31_RESULTS_20261024_KO.md)에 있다.

먼저 [시스템 개요](docs/MINIMAL_SYSTEM_KO.md)를 읽는다. [온톨로지·수식](docs/TOSM4_ONTOLOGY_KO.md), [실험 설계](docs/EXPERIMENT_DESIGN_KO.md)가 각각 구현과 검증을 설명한다.

```matlab
run_check              % 구조 검사 + 각 모델 1 update의 smoke, 본 학습 아님
run                    % 기본: v3.1 새 개발 시드 271–275 학습·일반화 평가
run_scenario('S2')      % 마커 누락 사례, 학습된 시드 271 필요
run_live('S3')          % 가속 사례의 센서 잡음 반복 비교
```

주 질문은 **온톨로지의 입력 배치·정보 경로·가중치 공유가 일반화에 도움이 되는가**다. [귀납적 편향과 업데이트](docs/INDUCTIVE_BIAS_KO.md)에 구현 원리를 정리했다. 편향을 점수화하지 않으며, 가속·누락·잡음을 각각 학습 범위 밖으로 바꾼 세 시험의 착륙률을 주 지표로 둔다. 관계 교란 대비와 PPO 대비를 학습 시드별로 비교하고 위험 접촉·추종 오차를 함께 확인한다.

`run.m`의 세 `train` 값은 true이며 사용자가 학습·평가를 실행한다. 새 결과는 `results/minimal_v31/`에 저장하고 기존 결과를 보존한다. 학습 효율은 보조 지표이며, 기존 held-out·S1 등속/S2 누락/S3 가속 사례는 `includeDiagnostics=true`로 추가한다. 확인 실험은 phase='confirmation', 시드 281:290, 세 train=true로 사용자가 실행한다.

이전 v3 개발 시드 251–255의 [결과 분석](docs/MINIMAL_V3_RESULTS_20261024_KO.md)은 보관 기록이다. v3.1의 성능 결과로 사용하지 않는다. 이전 구조·결정 추적 대시보드·개발 게이트는 [보관 문서](docs/archive/AGENTS_V2_20261024.md)와 [v2 이력](docs/RGAT_V2_DESIGN_KO.md)에 남겼다.
